# 正文结构规律

## 候选规律

### 规律 1：【总承诺 → 多个编号模块 → 总结或行动】
- 大白话解释：先告诉观众这条内容会交付一整套清单，再按编号、功能或选项逐项展开，最后把所有模块重新归纳，并给一个行动方向。
- 适合什么内容：赚钱路径清单、工具功能合集、一人公司部门配置、办公司选择和其他多模块知识内容。
- 不适合什么内容：只有一个核心观点、模块之间没有并列关系，或每个模块都需要大量背景才能讲清的内容。
- 不可照搬点：模块数量必须与正文一致；不能把本来属于同一步的内容硬拆成多个数字，也不能为了“全面”塞入无关模块。
- 结构顺序：结果或范围承诺 → 模块 1 → 模块 2 → 模块 3…… → 汇总模块价值 → 结尾行动。

### 规律 2：【具体痛点 → 工具方案 → 连续实操 → 展示结果 → 让观众尝试】
- 大白话解释：先说明一个人为什么做不到，再引出工具或系统，随后按真实操作顺序演示，最后展示成品或数据，并让观众自己试。
- 适合什么内容：AI 工具上手、数据分析工具、内容生产工作流和可录屏展示的教程。
- 不适合什么内容：没有实际操作界面、没有结果可展示，或关键步骤需要大量外部条件的内容。
- 不可照搬点：操作步骤不能靠想象补齐；工具名称、按钮、审核时间和输出效果都需要按实际版本核对。
- 结构顺序：用户痛点 → 工具为什么能解决 → 打开工具 → 设置任务或导入数据 → 分步操作 → 查看输出 → 解释价值 → 尝试、评论或关注动作。

### 规律 3：【抽象赚钱判断 → 生活或商品案例 → 可执行方法 → 回到一般原则】
- 大白话解释：先说一个抽象判断，再用具体的人、商品或生活小事证明它如何落地；讲完做法后，再把案例提升成观众可以迁移的原则。
- 适合什么内容：信息差、普通人技能变现、AI 赚钱案例和认知转行动内容。
- 不适合什么内容：案例与观点没有直接关系，或只能讲一个故事、无法提炼行动方法的内容。
- 不可照搬点：案例只是说明方法如何运转，不能据此保证所有人都能获得同样收入；涉及合同、收费和平台规则时需要另行核验。
- 结构顺序：提出赚钱判断 → 选一个具体案例 → 解释为什么有人愿意付费 → 给出操作方式 → 扩展到更多相似场景 → 回到一般赚钱原则或行动建议。

### 规律 4：【争议判断 → 证据和类比 → 回应质疑 → 风险或边界 → 作者立场】
- 大白话解释：先抛一个可能被反驳的判断，再补访谈、个人经历、案例或类比；中途主动回答质疑，最后讲清风险、适用边界或作者自己的选择。
- 适合什么内容：趋势解读、行业机会、商业判断和需要区分观点与事实的内容。
- 不适合什么内容：没有可靠来源、只有情绪判断，或内容篇幅不足以处理反对意见的内容。
- 不可照搬点：类比不能替代证据；作者经历、采访预测和商业宣传要分开标注，不能混成同一个已核验结论。
- 结构顺序：争议判断 → 来源或个人背景 → 证据与案例 → 类比解释 → 观众可能的反对意见 → 回应 → 风险、边界或适用条件 → 作者立场收束。

### 规律 5：【先讲为什么值得做，再进入怎么做】
- 大白话解释：教程没有立刻点按钮，而是先演示用途、列出可解决的场景，或补充行业背景；观众先理解价值，之后才进入操作。
- 适合什么内容：新概念工具、AI agent、智能体等观众可能不了解用途的教程。
- 不适合什么内容：观众已经明确知道目标，只想快速完成一个简单操作的内容。
- 不可照搬点：“为什么”部分不能无限延长；如果背景和案例占掉大部分篇幅，标题就不应承诺完整实操。
- 结构顺序：结果演示或行业背景 → 可解决的问题 → 概念解释 → 教程承诺 → 具体操作 → 成品展示 → 行动。

### 规律 6：【每一项都按“名称或选项 → 场景 → 操作或解释 → 结果”展开】
- 大白话解释：列清单时不是只报名称，而是给每一项安排一个具体场景，解释怎么用或怎么选，再说明会得到什么。
- 适合什么内容：工具功能合集、不同主体类型的选择、技能变现案例和多方案对比。
- 不适合什么内容：每个项目彼此高度依赖，无法独立说明，或正文没有空间给每项补案例的内容。
- 不可照搬点：每项需要的解释深度可以不同；不能为了格式整齐，给所有项目编造不存在的结果。
- 结构顺序：项目名称或选项 → 谁在什么情况下会遇到 → 如何操作或为什么这样选 → 可能得到的结果或需要注意的风险 → 下一项。

### 规律 7：【价值结论 → 具体观众动作】
- 大白话解释：正文结束前先用一句话收束价值，再让观众做一个与内容直接相关的动作，例如尝试工具、选择方向、评论技能、关注系列或分享作品。
- 适合什么内容：教程、清单、系列内容、评论区答疑和需要观众实际执行的内容。
- 不适合什么内容：风险尚未讲清，或动作与正文没有关系、只是统一喊关注的内容。
- 不可照搬点：动作应和内容承诺一致；“关注、点赞、评论”不能替代真正的结论，也不能暗示完成动作就能获得未经说明的结果。

### 规律 8：【先报案例结果 → 拆成立机制 → 提炼原则 → 迁移行动】
- 状态：待确认
- 结构顺序：人物身份或高额结果 → 市场、产品、交付、获客或自动化机制 → 用数字或付费行为说明结果 → 提炼案例原则 → 给普通人可执行的下一步或行动信念。

- 不可照搬点：必须区分案例事实、原作者解释和二次整理者的总结；个案方法不能直接写成普通人都能复制，也不能用收入结果代替成立条件。

### 规律 9：【方法或案例结论 → 不追加互动动作收尾】
- 状态：待确认
