# QCS 转化路径

让内容推动一个真实、明确且能够承接的下一步。一次只解决当前转化任务，不自动扩展为整篇广告稿、发布风险审查或商业模式重做。

## 启动读取

1. 找到包含 `AGENTS.md` 的 Vault 根目录，完整读取 `AGENTS.md` 与 `00_个人背景/定位总览_v0.1.md`。
2. 读取 `../qcs/references/shared-contract.md` 与 `../qcs/references/course-map.md`，只使用映射到 `qcs-conversion` 的方法。
3. 读取当前对话，以及与任务直接相关的最新单条编导卡、稿件、产品或服务资料、真实证据和现有承接页面或流程。修改编导卡前，再读 `../qcs/references/director-card-schema.md`。
4. 默认以 `01_学习对象/安先生/5.0课程逐字稿校订/核心方法校订_v0.1.md` 的“方向与定位”“观看与行动路径”为课程真源；需要结构化旧课补充时，只按任务读取 `01_学习对象/安先生/01-定位和策划思维.md` 或 `02-短视频的流量结构.md`。没有对应校订方法时标记限制，不从其他旧课猜规则。
5. 带货、本地生活、直播间或电商内容只在用户的真实任务确实匹配时，按课程映射读取对应专题；不把这些专题默认套到普通内容。

优先复用用户已给出的目标、产品、价格、证据和承接方式。只有缺失信息会改变行动路径时，才一次询问一个关键问题。

## 触发与排除

适用：

- 已有内容与真实承接对象，需要确定看完后的一个主要行动。
- 需要梳理真实卖点、证据、顾虑、CTA、落地位置或交付路径。

不适用：

- 本 Skill 设计“看完后做什么、为什么愿意做、下一步在哪里完成”；不负责批量找选题、搭建产品、建立销售系统或写完整正文。
- 没有真实产品、资料、咨询能力或承接页面时，不把不存在的路径写成已上线；先输出缺口和最小可行承接条件。
- 准备发布时的事实、合规与表达风险检查属于 `dbs-content-risk-check`；本 Skill 不替代它，也不自动调用它。
- 平台入口、抽佣、核销、投放、算法与限制可能变化；需要引用当前规则时，只使用当前官方来源核验后的信息。
- 不承诺播放、涨粉、咨询、下单或收入结果。

## 工作流

### 1. 锁定一个主要行动

先确认本条内容在“被看见—被理解—被信任—采取行动”中的主要位置，并只选择一个主要行动，例如关注、收藏、评论关键词、私信、领取资料、预约、进入页面或购买。

行动必须对应真实存在的承接位置、执行主体和交付能力。多个行动并列时，保留最能服务本条第一目标的一个，其余作为可选后续，不挤进同一条 CTA。

### 2. 建立转化事实卡

整理并区分：

- 适用对象及其具体问题；
- 产品、服务或下一步实际提供什么；
- 用户能得到的真实结果或使用价值；
- 已有证据与来源；
- 价格、条件、限制、成本或不适用对象；
- 观众当前最可能的真实顾虑；
- 从内容到承接、交付和后续跟进的实际路径；
- 待确认和禁止新增的说法。

不得编造案例、效果、稀缺性、库存、限时、用户评价或购买理由。

### 3. 找到当前最早的阻力

按需要检查：产生兴趣、理解利益、想象使用、建立信任、降低顾虑、接受条件、执行行动。不要机械把所有环节都塞进一条内容；只修复阻塞当前主要行动的最早一环。

卖点必须连接具体用户问题和可交付结果。证据不足时降低承诺或补证据，不用更强措辞代替事实。

### 4. 设计一条可承接路径

写清：

`内容中的触发点 → 主要行动 → 到达位置 → 用户会看到什么 → 谁来响应 → 交付什么 → 下一步是什么`

确保 CTA 的承诺与落地页、私信回复、资料、商品或服务实际内容一致。评论或私信关键词必须有真实响应方式；资料引流不能用与正文无关的诱饵。

### 5. 按真实场景专项处理

- **引流资料**：说明适用对象、资料内容、获取方式、交付方式和后续边界。
- **产品或广告**：围绕真实需求、卖点、使用场景、证据、限制和顾虑组织转化段，不靠虚假对立或夸张结果。
- **带货、本地生活、直播或电商**：先核对真实产品、利润与履约、门店或直播承接、渠道和当前平台规则；课程模板只作结构参考，不保证结果。

如果用户只是分析海外 AI 生意案例，应区分“案例中的转化链”和“本账号要观众采取的行动”，不要把案例销售路径误当成本账号已具备的业务。

### 6. 生成行动表达并按授权落盘

给出一个推荐 CTA 和必要时的少量备选，说明各自适用前提。用户要求保存或当前任务已授权更新时，只更新现有单条编导卡的目标、反馈点、结尾或承接路径字段；不另建销售稿、线索库或第二套编导卡。

## 产物

返回以下内容：

1. **当前判断**：本条处于哪一环，最早的转化阻力是什么。
2. **主要行动**：只保留一个目标动作及选择理由。
3. **转化事实卡**：对象、问题、真实价值、证据、限制与顾虑。
4. **承接路径**：从内容触发到响应和交付的完整下一步。
5. **行动表达**：一个推荐 CTA；有必要时给出不超过两个有明确前提的备选。
6. **风险交接**：需要发布前核验的事实、平台或合规问题，但不代替专项风险检查。
7. **来源与状态**：事实文件路径、课程方法路径及是否满足完成标准。

## 完成标准

- 目标观众、内容承诺、主要行动、到达位置和实际交付彼此一致。
- 只保留一个主要 CTA，并能说明观众此刻为什么愿意行动。
- 卖点、证据、限制和顾虑都来自真实材料或明确标为待确认。
- 承接页面、回复主体与交付方式真实存在；不存在时已明确列为阻塞项。
- 没有编造效果、稀缺性、评价或保证性结果，也没有把过时课程经验写成当前平台规则。
- 只完成转化路径设计，没有自动写整篇稿、执行风险审查、调用其他 Skill 或创建第二套内容文件。
