# 选题池输出与增量合并约定

执行 `shengcai-topic-generator` 时完整读取本文件。

## 有效素材

扫描 `02_内容素材` 下的 Markdown 文件，并排除：

- `搜索关键词.md`
- `_入库检查报告.md`
- 其他文件名以 `_` 开头的辅助文件

有效素材必须同时具备：

1. Markdown 一级标题中的真实标题。
2. “视频链接”“笔记链接”“来源链接”或文件中明确的来源网址。
3. `## 正文` 区域中的可读正文。

空白、占位语以及“未提供”“未采集”“无”“暂无”视为缺失。缺项素材不进入选题生成，不补写、不推测，在报告中列出路径和缺失项。

## 本地图片

- 按素材文件中的嵌入顺序读取全部本地图片。
- 图片文字只用于理解内容实际讲了什么。
- 选题的来源仍写对应的 `笔记信息.md`，不把图片路径作为独立来源。
- 图片不存在或无法读取时记录完整路径和原因；影响选题判断时标记“缺素材”。

## 选题格式

文件：`04_选题库/选题池.md`

首次创建时使用一级标题：

```markdown
# 选题池
```

每条选题使用以下字段：

```markdown
## 选题 01：准备讲什么

- 准备写给谁：明确读者
- 解决的具体问题：一个具体问题
- 准备讲什么：本选题准备解释的内容范围
- 素材状态：材料基本够用 / 缺素材
- 缺少什么：无 / 需要补充的具体材料
- 主要来源：
  - `02_内容素材/……/笔记信息.md`
```

约束：

- 选题名称只表达准备讲什么，保持中性、清楚。
- 不使用“必爆”“神级”“一定赚钱”等素材无法证明的包装。
- 不生成吸引点击的标题版本，不写开头、结构、大纲或正文。
- “主要来源”只列实际用于形成该选题的有效素材，不为了显得充分而堆路径。
- 关键事实仅来自中文二次整理时，素材状态写“缺素材”，并说明需要哪类原始来源。

## 已读取素材

选题池文末保留一个“已读取素材”区域：

```markdown
## 已读取素材

- `02_内容素材/……/笔记信息.md`
```

首次生成记录全部已读取的有效素材。增量生成记录本轮成功读取的全部新增有效素材，包括没有形成新选题的素材，以免后续重复处理。

同一路径只记录一次。识别素材是否已处理时，同时比较：

1. 规范化后的素材路径；
2. 笔记、视频或内容 ID；
3. 规范化后的来源链接。

任一项相同即视为已处理。

## 语义去重

比较每个候选方向和既有选题的：

- 准备写给谁；
- 解决的具体问题；
- 准备讲什么；
- 读者看完应理解的核心结论。

主要问题和核心讲法相同即视为重复。以下变化不能单独形成新选题：

- 更换 AI 工具名；
- 更换案例人物、国家或行业；
- 更换收入、粉丝或播放数字；
- 使用近义词重写同一个问题；
- 把一个已有选题改成疑问句或陈述句。

同一素材可以支持不同选题，但必须解决不同问题，并给读者带来不同的核心理解。

## 首次写入

1. 有效素材少于 10 条时停止，不创建选题池。
2. 生成 5—10 个不重复选题。
3. 按顺序编号，从 `选题 01` 开始。
4. 文末写“已读取素材”。

如果选题池已经存在但没有可识别的“已读取素材”区域，不把它当成空文件覆盖；停止并报告格式问题。

## 增量合并

1. 把所有既有选题视为用户已确认内容。
2. 不删除、不覆盖、不改写、不重排、不重新编号既有选题。
3. 新选题从当前最大编号继续。
4. 把新选题插入“已读取素材”区域之前。
5. 只向“已读取素材”列表追加新路径，不改写原有记录。
6. 新材料足够时生成 5—10 个不同选题；不足时允许少于 5 个，并在报告中说明原因。
7. 没有不重复的新选题时不凑数，只追加已读取素材并报告重复原因。

## 完成报告

报告以下内容：

- 有效素材总数；
- 新增有效素材数；
- 本次生成或追加的选题数；
- 因重复被排除的方向；
- 缺素材的选题和具体缺口；
- 图片缺失或无法读取问题；
- `04_选题库/选题池.md` 的具体位置。
