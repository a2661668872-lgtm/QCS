# 航海选题助手

从真实入库素材中生成符合账号定位的候选选题。默认保护所有既有选题，增量模式只处理新素材并追加不同的新选题。

## 开始前

1. 找到当前 Obsidian Vault 根目录。
2. 完整读取根目录的 `AGENTS.md`（如存在）和 `00_个人背景/定位总览_v0.1.md`。
3. 完整读取 [references/output-contract.md](references/output-contract.md)，遵守其中的有效素材、选题字段、去重和合并约定。
4. 不修改 `00_个人背景` 或 `02_内容素材` 中的文件。

## 盘点素材和选题池

优先运行只读脚本：

```powershell
python scripts/inventory_materials.py --vault-root <Vault根目录> --pretty
```

如果系统的 `python` 不可用，寻找当前 Codex 提供的 Python 运行时；仍不可用时，按脚本中的同等规则人工盘点，不跳过有效性、增量和图片引用检查。

脚本只读取文件并输出 JSON，不执行 OCR，不修改选题池。它使用素材路径、笔记或视频 ID、来源链接识别已处理素材，并给出：

- 有效、无效、已处理和新增素材数量；
- 既有选题数量、最大编号和已读取素材数量；
- 每条素材的缺失字段和本地图片路径。

只把同时具有真实标题、来源链接和可读正文的文件视为有效素材。排除 `搜索关键词.md`、`_入库检查报告.md` 和其他文件名以 `_` 开头的辅助文件。

## 选择模式

- `04_选题库/选题池.md` 不存在：执行首次生成。
- 选题池存在且含有“已读取素材”：执行增量生成。
- 选题池存在但没有可识别的“已读取素材”：停止，不覆盖或重建文件；报告格式问题并等待用户处理。

首次生成前检查有效素材总数。少于 10 条时立即停止，不创建选题池，并报告有效数量和还缺多少条。

增量模式没有新增有效素材时，不修改文件，直接报告盘点结果。

## 读取正文和图片

1. 首次模式读取全部有效素材；增量模式只读取脚本列出的新增有效素材。
2. 读取标题、来源链接和正文原文。
3. 按 Markdown 嵌入顺序定位全部本地图片，使用视觉读取能力逐张查看。
4. 把图片文字视为理解内容的材料，但来源仍记录对应的 `笔记信息.md`，不把图片路径列成独立内容来源。
5. 图片缺失、损坏或无法读取时，记录具体完整路径和原因，不跳过、不推测；如果缺图影响选题成立，把选题标记为“缺素材”。

## 生成候选选题

结合定位文件中的目标读者、账号价值、内容范围、内容支柱和暂时不做的方向进行筛选。

每个候选选题必须：

1. 对应一个明确读者和一个具体问题。
2. 只说明准备讲什么，不优化成夸张标题，不写开头、正文结构或逐字稿。
3. 使用当前已读取素材能够支持的内容，不编造趋势、需求、案例、个人经历或使用效果。
4. 记录实际使用的具体素材文件路径。
5. 对缺少本人视频、采访、品牌官网、公开账号或关键数据依据的案例标记“缺素材”，写清缺口。
6. 不把中文博主的二次整理包装成已经独立核验的事实。

首次生成 5—10 个不同选题。增量模式在新材料足够时追加 5—10 个不同选题；材料不足时只生成真正成立的数量并说明原因，不凑数。

## 语义去重

生成前为每个候选方向概括四项：目标读者、具体问题、核心内容、预期收获。与全部既有选题逐条比较：

- 主要问题和准备讲的核心方法相同，视为重复。
- 只更换工具名、人物、行业、收入数字或近义表达，视为重复。
- 使用同一素材但解决不同问题，不自动视为重复。
- 新素材只能补强旧选题、不能形成新问题时，不新增选题；在完成报告中说明可补强方向，等待用户决定是否修改旧选题。

## 写入选题池

首次模式按 [references/output-contract.md](references/output-contract.md) 创建 `04_选题库/选题池.md`，并在文末记录本轮读取的全部有效素材。

增量模式执行以下合并：

1. 把所有既有选题视为用户已确认内容，不删除、不覆盖、不改写、不重排、不重新编号。
2. 从现有最大编号继续编号。
3. 把新选题插入现有“已读取素材”区域之前，不改变原有行。
4. 把本轮成功读取的新素材路径追加到“已读取素材”列表，去除重复记录。
5. 即使新增素材全部与旧选题重复，也要记录这些已读取素材，但不新增选题。
6. 如果合并需要改变任何既有选题的文字、状态或来源，停止该改动并报告，等待用户确认。

## 完成检查

完成前确认：

- 定位文件已读取，选题没有超出内容范围。
- 首次生成时有效素材不少于 10 条。
- 所有应读取的本地图片均已按顺序检查，失败路径已记录。
- 每个新选题都有明确读者、具体问题、准备讲什么、素材状态和真实来源路径。
- 没有生成标题包装、开头、正文结构或正文。
- 新选题与既有选题不存在仅换工具、数字、人物或近义词的重复。
- 既有选题和编号没有被修改。
- “已读取素材”记录完整且不重复。

最后报告：有效素材总数、新增有效素材数、本次生成或追加的选题数、因重复被排除的方向、缺素材风险、图片读取问题，以及选题池文件位置。
