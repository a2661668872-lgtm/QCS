# 输出契约

## 文件命名

- 素材包：`05_内容草稿/编号_【选题关键词】_素材包.md`
- AI 初稿：`05_内容草稿/编号_【选题关键词】_AI初稿.md`
- 最终发布稿：`05_内容草稿/编号_【选题关键词】_最终发布稿.md`

`编号`固定为三位数字，例如 `001`。实际文件名不保留方括号；例如 `001_AI智能体和普通聊天工具_素材包.md`。

## 素材包格式

```markdown
# 第N篇内容：【选题】

## 素材包

- 选题：
- 写给谁：
- 解决什么问题：
- 来源文件：
- 可用规律：

### 图片文字材料

逐条记录：
- 来源文件：
- 来源图片：
- 图片中的原始信息或必要摘录：
- 准备用在什么位置：

没有本地图片时写“未采集”。图片无法读取时记录完整路径和原因。

### 可用材料

逐条记录：
- 来源文件：
- 原始信息或必要摘录：
- 准备用在什么位置：

### 本条结构参考（有合适对标时填写）

- 主对标：具体路径或链接、主要节点及其段落功能、可借鉴的推进关系、不能搬用的原作者信息；只有文字稿时不写画面判断。
- 辅助片段：逐项记录具体路径或链接、本人旧稿/外部稿件、原段落功能、拟用节点、必要摘录或改写候选、采用或舍弃理由。
- 迁移缺口：没有本条真实材料支撑的节点；无合适对标时写“无”，不硬套。

### 我的理解与判断

（访谈后填写）

访谈完成后，每条按以下形式记录：
- 本人回答：……

### 待核查或待补充
```

来源文件使用 Vault 根目录下的具体相对路径。必要摘录只保留支持写作判断的信息，不大段复制来源正文。

```markdown
# 第N篇内容：【选题】｜AI 初稿

> 当前状态：AI 初稿，尚未确认，不是最终发布稿。

## 标题候选

1. **标题**
   - 调用规律：
2. **标题**
   - 调用规律：
3. **标题**
   - 调用规律：

## 采用规律

- 标题规律：
- 开头规律：
- 正文结构规律：
- 本条对标结构参考（若有，非通用规律）：
- 选择原因：

## 正文初稿

……

## 素材调用清单

- 素材包：
- 来源文件及使用内容：
- 图片引用及读取情况：
- 规律调用：
- 主对标及辅助片段调用（若有）：

```

素材调用清单只写内部追溯信息，不把读取、OCR、文件路径或处理方法混进正文。

## 最终发布稿格式

```markdown
# 【用户选定标题】

【用户修改后的发布正文与已确认本地配图引用】
```

最终稿只保留标题、发布正文和用户确认的本地配图引用。不得保留以下内容：

- 标题候选、规律名称和规律说明；
- 素材读取过程、路径清单和图片识别说明；
- 素材调用清单、状态说明和内部备注；
- `【待补图片】`、`【待核查】`；
- 未完成核查的产品事实。

整理最终稿时不重新创作。只允许修正语病、口语重复、明显错别字、标点、分段和大小写；不得改变用户核心判断或补充新的内容。
