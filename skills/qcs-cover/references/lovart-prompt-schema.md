# Lovart 封面提示词结构

Lovart 提示词采用设计任务书，而不是关键词堆砌。每个最终提示词都必须替换为本条内容的具体信息，不得保留下列字段名、说明语或占位符。

## 完整提示词层级

### 1. 任务

说明：为哪条短视频、哪个平台制作什么比例的封面，只要求一张最终画面。

应具体包含：内容主题、平台、方向、比例。

### 2. 受众与信息任务

说明：谁会看到这张封面，以及观众第一眼必须理解的一件事。

不要把完整账号定位全部复制进提示词，只保留会改变这张封面判断的信息。

### 3. 画布与安全区

说明：横竖方向、比例、标题和主体的安全区、移动端缩略图可读性。

除非已有当前可靠依据，不写固定像素、裁切阈值或平台算法偏好。

### 4. 主体与构图

按视觉层级写清：

- 第一焦点是什么；
- 人物或素材位于哪里，占画面多少；
- 前景、中景和背景分别承担什么任务；
- 标题与主体是否遮挡；
- 箭头、卡片或界面怎样引导视线。

人物参考图存在时，要求保持人物身份和自然比例，但不复述或猜测外貌。没有人物图时，直接写素材主体方案。

### 5. 标题排版

标题必须作为明确的中文排版文字，并写清：

- 标题原文，要求一字不改，不增加其他主标题；
- 分行方式和视觉层级；
- 大致位置与占比；
- 字体气质、主色、强调色、描边或底板；
- 缩略图状态下仍可读，不能遮挡人物眼睛、嘴巴或关键证据。

如果 Lovart 支持可编辑文字，要求把标题保留为清晰的排版元素，不把文字融成图片纹理。

### 6. 视觉语言

只选择会服务信息任务的视觉元素：背景、明暗关系、两到三种主色、轮廓、卡片、箭头、贴纸、界面或材质。避免用“高级感”“爆款感”代替具体画面决定。

不要求复刻某位创作者的个人风格。可以具体描述大标题、高对比、人物抠图、信息卡片等功能性特征。

### 7. 参考素材

逐项写清上传素材的用途，例如：

- 人物参考图：保持身份，用于前景半身人物；
- 来源截图：保持核心文字或界面结构，用于证据卡；
- 产品图：保持形态、颜色和 Logo，不重新设计产品；
- 配色参考：只提取标题主色、强调色和描边逻辑。

没有上传的素材不能写成已经提供。用户为说明任务而上传的 Lovart 页面或操作截图，不自动成为封面素材。含有头像、用户名、订单、客户、通知、Cookie、Token 或其他隐私和不可公开信息的素材不得进入提示词。

### 8. 事实与质量约束

按本条风险选择必要约束：

- 不新增未提供的数字、结论、Logo、产品功能、界面文字或来源。
- 副标题、标签、清单、贴纸等辅助文字也不能新增未经确认的事实或效果承诺。
- 不把来源方说法改成独立核验结论。
- 不生成财富、成交或效果保证的视觉暗示。
- 不改变人物身份，不拉伸脸和身体，不出现异常手指或多余肢体。
- 不让标题错字、漏字、乱码、重复或越出安全区。
- 不让背景、装饰或素材卡片抢过标题和主视觉。
- 不添加水印、二维码、账号名或未要求的额外文案。

## 输出格式

按以下顺序交付：

1. 当前判断；
2. 素材使用；
3. 主提示词代码块；
4. A 方案唯一测试变量与完整提示词代码块；
5. B 方案唯一测试变量与完整提示词代码块；
6. 本条事实与隐私边界；
7. 完成状态。

每个代码块必须可以独立复制。A、B 方案不得写成“同上，只修改……”的增量命令。

## 单变量规则

先找最不确定、最可能影响点击后理解的两个视觉决定，再分别测试：

- 标题层级：整块大标题与核心词拆分；
- 主体主次：人物主导与证据素材主导；
- 信息密度：一个辅助卡与三个短节点；
- 背景明暗：浅色信息板与深色高对比背景；
- 表情或姿势：自然解释与更强动作；
- 证据位置：侧边证据卡与底部证据条。

每个测试版本只从中选择一个变量。标题承诺、事实、平台比例、核心素材和其余视觉规则必须与主方案一致。

## 交付检查

- 平台和比例是否明确；未说明平台时是否使用小红书 3:4。
- 第一眼是否只有一个主要焦点。
- 标题是否逐字保留且缩小后可读。
- 人物、产品、界面和来源截图是否都有真实输入与明确用途。
- 数字、效果和来源属性是否与材料一致。
- 是否暴露公司、账号、头像、用户名、订单、客户、通知、Cookie、Token 或其他隐私。
- 人物脸、手、身体和产品形态是否有明确的防变形约束。
- 是否避免遮脸、错字、乱码、越界、水印和多余文案。
- A、B 是否各自只有一个声明的测试变量。
- 是否删除所有模板占位符和“由模型决定”式描述。
