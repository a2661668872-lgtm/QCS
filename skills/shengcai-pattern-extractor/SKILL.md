# 航海规律提取助手

从真实入库素材中整理统一底稿，再提炼可追溯、可人工确认的标题、开头和正文结构规律。默认增量处理，保护用户已经确认的内容。

## 开始前

1. 找到当前 Obsidian Vault 根目录。
2. 完整读取根目录的 `AGENTS.md`（如存在）和 `00_个人背景/定位总览_v0.1.md`。
3. 完整读取 [references/output-contract.md](references/output-contract.md)，严格遵守其中的字段、格式、有效素材和合并约定。
4. 不修改 `02_内容素材` 中的原始素材。

## 盘点素材

优先运行只读脚本：

```powershell
python scripts/inventory_materials.py --vault-root <Vault根目录> --pretty
```

如果系统的 `python` 不可用，寻找当前 Codex 提供的 Python 运行时；仍不可用时，按脚本定义的同等规则人工盘点，不因此跳过有效性和重复检查。

脚本只负责识别候选文件、有效素材、已处理素材、新增素材和图片引用，不负责 OCR，也不写文件。

只把同时具有真实标题、来源链接和可读正文的文件视为有效素材。排除 `搜索关键词.md`、`_入库检查报告.md` 和其他文件名以 `_` 开头的辅助文件。字段为空或值为“未提供”时，视为缺失。

## 选择处理模式

- `03_内容规律/_规律提取汇总.md` 不存在时：对全部有效素材执行首次汇总。
- 汇总已存在时：只处理脚本列出的新增有效素材。
- 用户明确要求重查某条旧素材时：只重查用户指定的素材，不顺带重做其他旧素材。
- 没有新增有效素材时：不重写任何规律文件，直接报告盘点结果。

素材路径与视频或笔记 ID 任一已经出现，都视为已处理，防止文件改名后重复入库。

## 读取正文与图片

1. 读取素材文件里的标题、来源链接和正文原文。
2. 按 Markdown 中的嵌入顺序定位全部本地图片。
3. 使用视觉读取能力逐张查看图片，把可读文字视为正文的一部分，并单独记录为图片正文。
4. 分开判断“笔记文字开头”和“图片内容开头”，不得把图片中的句子冒充笔记文字原文。
5. 图片只有装饰且无可读文字时，写“无可读文字”。
6. 图片不存在、损坏或无法读取时，记录具体完整路径和失败原因；不得跳过、猜测或补写。

## 更新汇总底稿

按 [references/output-contract.md](references/output-contract.md) 的“汇总格式”把新增素材追加到 `03_内容规律/_规律提取汇总.md`：

- 保留既有素材编号和内容，不整体重排或重写。
- 新素材从当前最大编号继续编号。
- 缺失字段统一写“未采集”。
- “开头 1-3 句原文”保留原文，不改写。
- “正文结构”按原文实际推进顺序用箭头列出，不提前压缩或合并步骤，并包含结尾动作。

## 更新三类规律

基于完整汇总底稿，增量更新：

- `03_内容规律/标题规律.md`
- `03_内容规律/开头规律.md`
- `03_内容规律/正文结构规律.md`

执行以下判断：

1. 同一种做法至少由 2 条不同有效素材支持，才能进入“候选规律”；只出现 1 次的放进“单条观察”。
2. 单条观察获得第二条证据时，可升级为候选规律，并保留全部来源。
3. 新素材支持已有规律时，只追加来源和必要证据，不重复创建同义规律。
4. 标题规律先保留并检查全部完整标题，再识别反复出现的元素组合，不能只统计孤立词语。
5. 开头规律保留 1-2 句来源原文作为示例，注明来自笔记文字还是图片正文，不改写原文。
6. 正文结构规律写清实际结构顺序和适用内容类型，同时使用笔记正文与图片正文。
7. 每条候选规律都写明：大白话解释、适合什么内容、不适合什么内容、不可照搬点、来源素材。
8. 不写“这样一定会爆”“平台算法喜欢”等当前素材无法证明的因果结论。
9. 需要改写示例时，明确标注“AI 示例”，不得冒充素材原文。
10. 每份规律文件末尾保留并更新“待确认”清单。

## 保护已确认规律

把带有以下状态的规律视为受保护内容：

- `本期可用`
- `以后再试`
- `已删除`

不要删除、覆盖、改名、改写或改变这些规律的状态、解释、适用范围、不可照搬点和删除原因。对“本期可用”或“以后再试”的规律，可以在不改变原意的前提下追加新的来源素材和证据。

不要恢复“已删除”规律，也不要把相同意思换名后重新加入。若新增证据可能需要改变受保护规律的语义或状态，把建议写入“待确认”，等待用户决定。

用户明确给出确认修改时，只执行用户说出的改动；被删除的规律移动到文末“已删除”区域并保留删除原因。

## 完成检查

完成前逐项确认：

- 原始素材未被修改。
- 新增素材没有重复汇总。
- 所有本地图片均按顺序检查，失败路径已记录。
- 候选规律均有至少 2 条不同来源素材。
- 单条做法没有混入候选规律。
- 三份规律文件都包含“待确认”。
- 用户已确认的规律和状态未被覆盖。
- 新增来源使用具体素材文件路径。

最后报告：有效素材总数、新增有效素材数、本次追加的汇总条数、三类规律的新增或补强数量、缺失字段、图片读取问题，以及需要用户人工确认的结论。
