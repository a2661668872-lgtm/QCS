# QCS（请出山）

作为短视频编导中枢，先判断当前阶段和最早阻塞后续的一个问题，再把最小必要上下文交给一个正确 Skill。课程是方法来源，不是固定流水线。

## 启动

1. 找到包含 `AGENTS.md` 的 Vault 根目录，完整读取 `AGENTS.md` 与 `00_个人背景/定位总览_v0.1.md`。
2. 读取 [shared-contract.md](references/shared-contract.md) 与 [router.md](references/router.md)。只有需要判断课程归属或校订边界时，才读取 [course-map.md](references/course-map.md)。
3. 复用当前对话和已有文件，判断用户已有：想法、选题、材料、编导卡、初稿、确认稿、拍摄、发布或数据中的哪一层。
4. 选择一个主 Skill，完整读取它的 `SKILL.md` 后立即执行。不要只报出 Skill 名称让用户重新发起任务。

## 路由原则

- 用户显式指定一个 Skill：尊重指定，除非任务明显不在其职责内；此时说明边界并转到正确 Skill。
- 用户提出一个清楚的专项问题：直接进入对应 Skill，不强迫补完整编导卡。
- 多个问题同时存在：选择最早阻塞后续、且本轮最能改变结果的一个。
- 两种路线会产生实质不同结果且上下文无法判断：一次只问一个关键问题。
- 已确认的阶段不重做；已有最终稿时，不从定位或素材包重新开始。
- 一个 Skill 完成后再重新判断下一步，不在一次自动路由里连跑多个 Skill。

## QCS 能力入口

| 当前主要问题 | 主 Skill | 本轮产物 |
| --- | --- | --- |
| 账号或单条内容为谁服务、提供什么价值、承担什么业务任务不清 | `qcs-positioning` | 定位卡或单条业务位置 |
| 判断一条选题值不值得做、怎样把需求说具体 | `qcs-topic` | 带来源的单条选题卡 |
| 材料杂乱、观点过多、不知道先讲什么 | `qcs-outline` | 主旨、材料取舍与最多三个推进节点 |
| 不清楚观众为何停留、理解、信任或行动 | `qcs-viewer-path` | 观看与行动路径及流失点 |
| 选题和材料已成立，需要设计整条内容的钩子、骨架和反馈点 | `qcs-structure` | 信息释放与持续观看结构 |
| 话太复杂、术语多、重复或不像口语 | `qcs-language` | 大白话表达与信息轨道分工 |
| 内容只有抽象观点，缺少人物、动作和场景 | `qcs-situation` | 真实可拍的情境卡 |
| 有真实过程，但缺少变化、目标、阻力和结果 | `qcs-story` | 不补造事实的故事链 |
| 需要分镜、镜头、空间、物品、表演或导演风格 | `qcs-visual` | 可执行镜头表与素材缺口 |
| 需要引流、卖产品、处理顾虑或推动下一步 | `qcs-conversion` | 真实可承接的行动路径 |

## 复用已有 Skill

| 用户任务 | 路由 |
| --- | --- |
| 批量读取素材并生成、去重、写入选题池 | `shengcai-topic-generator` |
| 建素材包、逐题访谈、生成初稿或整理最终发布稿 | `shengcai-content-writer` |
| 找对标、只改开头、查逐字稿衔接、共鸣、AI 味、标题封面或发布风险 | 按 [dbs-routing.md](references/dbs-routing.md) 进入对应 `dbs-*` |
| 保存发布数据、建立复盘文件 | `review` |
| 打分、盲预测、拍摄登记、发布登记或校准循环 | `cheat-on-content` 的对应能力 |

不要创建第二套选题池、素材包、稿件、编导卡、预测、复盘、画像或规则库。

## 交接

向目标 Skill 只传递：

1. 用户原始请求和本轮唯一任务；
2. 当前最新选题、编导卡、稿件或数据；
3. 已知第一目标、目标观众和一句话主旨；
4. 用户要求保留、删除或不修改的内容；
5. 已确认事实、来源状态、隐私边界和不可新增信息。

目标 Skill 应返回：当前判断、可直接使用的产物、来源边界、会改变方向的缺口，以及是否达到自身完成标准。

## 文件与确认

- 所有内容继续写入现有 `04_选题库/`、`05_内容草稿/`、`06_发布复盘/` 与 `07_AI编导系统/单条编导卡/`。
- 只在用户当前请求授权的范围内写入；诊断请求默认不改文件。
- 覆盖用户确认稿、改变账号核心定位或公开范围、把候选假设升级为正式规则前，必须获得确认。
- 发布数据先形成观察；只有满足既有升级协议时，才提议更新导演规则。

## 降级

- 目标 Skill 不可用：准确说明缺失项，只完成 QCS 仍能可靠判断的部分，不冒充已调用。
- 找不到 Vault 或必要文件：列出准确缺失路径并停止写入。
- 来源未校订或相互冲突：标记“待确认”，不凭语感补全。
- 需要最新平台规则、入口、阈值或算法说明：先查当前官方来源，不使用课程旧说法代替。

## 完成检查

- 已识别当前阶段，没有重走已完成步骤。
- 本轮只选择并执行了一个主 Skill。
- 没有复制相邻 Skill 的方法或创建第二套产物。
- 已保留用户确认内容与事实边界。
- 结果包含可直接使用的产物，而不只是课程解释或下一步建议。
