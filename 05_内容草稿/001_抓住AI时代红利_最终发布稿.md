# 抓住AI时代红利 很多人还没意识到

一定要，一定要想尽一切办法用上 Codex。至少我不允许我的粉丝，到现在还没有用上 Codex、Claude。

如果你跟身边做互联网的朋友，从来没有聊过 Codex、Claude Code、Gemini，那恭喜你刷到这条视频，这可能真的是一次很重要的信息差。

Codex 到底是什么？就连英伟达的黄仁勋现在都要求很多员工都在用codex，在我看来，它不只是一个工具，更像是下一代生产力。

很多人用了很久的 AI，还是停在问问题、要答案。Codex 真正让我有感觉的一次，是我把一项真实业务直接交给了它：按照我的需求，去找美国门店客户。

它没有给我列一堆“找客户的方法”，而是直接去各大海外社媒平台找门店账号，再从账号里找联系方式。

最后，它整理出 1000 多家客户，做成优先建联表格。哪些客户先联系、每一家客户的私信怎么发，它也一起写好了。

而且 Codex 最大的价值在于，普通人终于真正开始调用 AI 的能力了。以前很多事情，你不会写代码，根本碰不到。现在不一样了。

如果你是大学生、职场人，或者打算创业，那其实挺幸运的，因为你刚好碰上了一次非常大的技术切换。

这像什么呢？就像你在食堂排队打饭，旁边突然新开了一个窗口。这个时候最重要的不是站在原地研究，而是赶紧过去。很多机会，本来就只属于第一批反应过来的人。
