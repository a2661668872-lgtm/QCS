# 安先生 5.0 课程到 QCS 能力映射

本表覆盖 `5.0课程逐字稿目录.md` 的 38 条课程记录。每条只有一个主要归宿；“共享”或“示例”不代表新增 Skill。

## 使用规则

- 默认从 `核心方法校订_v0.1.md` 的对应章节取方法，再按需读一份旧版结构化课题笔记。
- `_校订索引.md` 中的“方法级校订完成”只表示核心方法可用，原始全文仍未逐句校音。
- 标为“原稿待校音”的专题只提供问题分类或场景线索，不固化模板、平台规则、数字和因果结论。
- 标为“高级试验”或“示例”的课题不得成为每条内容的默认步骤。
