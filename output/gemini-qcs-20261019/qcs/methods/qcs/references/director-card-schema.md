# 单条编导卡字段与关卡

## 目录

1. 文件位置与状态
2. 必填字段
3. 四个确认关卡
4. 完成标准

## 文件位置与状态

把每条卡片放在：

`07_AI编导系统/单条编导卡/YYYY-MM-DD_选题关键词.md`

状态只能依次前进：

`想法 → 方向已确认 → 证据已确认 → 大纲已确认 → 初稿中 → 最终稿 → 已拍 → 已发布 → 已复盘`

不要因为用户已经提供最终稿而强迫其倒退补齐所有关卡。对于已有稿件，补充能支持当前诊断的字段，并把未知项标记为“未记录”。

## 必填字段

### 任务字段

- 选题与平台。
- 目标观众。
- 观众的一个具体问题。
- 第一目标：拉新、信任、行动或实验。
- 目标认知或行为变化。
- 一句话主旨。
- 唯一主要实验变量。

### 证据字段

- 本人经历和数据。
- 原始来源与路径。
- 本人判断。
- 课程方法。
- 待核查和禁止使用信息。
- 用户要求原样保留的句子。

### 结构字段

- 开头承诺。
- 三个以内的推进节点。
- 每个节点的证据。
- 方法或判断的出现位置。
- 结尾带走内容。
- 本条对标结构参考及辅助片段映射（仅在采用时记录来源、作用和取舍，不当成已验证规则）。

### 视觉字段

- 每段画面主体与动作。
- 录屏、界面、表格、来源或结果。
- 口播、旁白、字幕和环境声分工。
- 拍摄难点、缺失素材和替代方案。

### 数据字段

- 发布前预测文件。
- 实际拍摄稿是否改变。
- 发布链接与时间。
- 复盘文件。
- 本条产生的观察或假设编号。

## 四个确认关卡

1. **方向确认**：用户、问题、第一目标和一句话主旨。
2. **证据确认**：哪些能说、哪些需归因、哪些不能说。
3. **大纲确认**：推进顺序与删掉的支线。
4. **最终稿确认**：正文和标题由用户确认后才进入预测。

画面方案可以与大纲同步迭代，但发布前必须完成。

## 完成标准

- 只解决一个主要问题。
- 开头承诺能在前段兑现。
- 每个重要判断有证据、案例或明确归因。
- 画面承担信息，不只是装饰。
- 用户确认原话没有被同义替换。
- 只有一个主要实验变量，避免复盘时无法归因。
