# qcs-language：文字与语言基本功

把抽象、泛泛、需要读者费力联想的文字，改成可感知、可验证、低认知负荷的表达。

## 这套方法服务于什么

三层目的，逐层依赖：

| 层 | 目的 | 靠什么实现 |
|---|---|---|
| 底 | 被听进去 | 短句 + 动作，不费脑 |
| 中 | 被相信 | 专属细节作为证据 |
| 顶 | 被传播 | 单句独立可懂，抗变形 |

**「去 AI 味」是这三层达成后的副产品，不是目标。** 只盯着删副词、打乱三段式，文字依然抽象、依然不可信 —— 这是多数去 AI 味提示词失效的原因。

底层场景约束：观众一边做别的事、很疲惫，甚至边开车边看。抽象表达要求观众联想，很费脑子，因此传不进去。短视频看三秒忘三秒，长句要求同时持有前后半句才能理解，等于强制调用工作记忆。

## 模式判断

- 用户给文本 + 说「检查」「看看有什么问题」「标一下」→ **模式 A：标注**（默认）
- 用户明确说「改写」「帮我改成」「重写这段」→ **模式 B：改写**
- 未指明时，**默认走模式 A**。改写会让模型重跑一遍生成，容易引入新的 AI 味；标注保留原句，只暴露病灶，由人决定改不改。

---

## 模式 A：标注（默认）

通读全文，逐条输出：

```
【原句】<照抄原文>
【问题】<属于下面哪一类>
【可补什么】<提示细节方向，但不代写>
```

不输出修改后的版本。文末给一句总体判断：最需要解决的 1 个问题是什么。

### 问题分类

1. **抽象判断** —— 情绪词、形容词、状态描述。例：「他很沮丧」「效果好」「氛围感强」
2. **泛泛而谈** —— 缺时间、地点、身份、数量、专属名。例：「我很喜欢喝咖啡」
3. **长句依赖** —— 单看半句读不懂，必须结合前后文
4. **空容器** —— 「某种事物」「一件事」「一个东西」「进行/开展/实现/提升/赋能」
5. **副词堆砌** —— 「非常/快速地/悲伤地」等 telling 标记

## 模式 B：改写

按下列规则执行，改写后必须自检。

### 规则 1：be → do（抽象变动作）

把「是什么 / 感觉怎样」改写成动作或可观察场面。

剧本不能写心理描写 —— 情绪、形容词都是抽象的，观众对不上画面。

- 「这是一份用可乐做成的肥牛」→「我们给肥牛浇上可乐」
- 「我很悲伤，感觉昏天黑地」→「每天晚上回到家，你就在门口站了很久，一直不想推开门」

### 规则 2：专属细节五槽位

每个判断后面必须能填出至少 2 个槽位：

| 槽位 | 弱 | 强 |
|---|---|---|
| 时间 | 有一天 | 4 月 16 号下午三点 |
| 地点 | 放在家里 | 放在床头柜 |
| 职业身份 | 我工作的时候 | 我每次打开电脑上内部直播课的时候 |
| 数量 | 买了很多 | 一本书、两件毯子、五杯咖啡 |
| 专属物品 | 笔记本 | 灯塔笔记本 / 老盐黄皮水 |

**判据：所有泛泛而谈的内容都不会有流量。** 谁不知道要热爱生活 —— 得让读者看到你具体怎么热爱。

### 规则 3：短句优先

短句 = 只有主谓宾，没有从句、补语、长状语。

**擦掉检验法（最可执行）**：把文案按逗号拆成一行一句，遮住其他句子，只看这一句 —— 能读懂即为短句，读不懂就是长句。

- 度量：拆成五六个字去讲，不要拉成长段
- 理由：长句 = 信息复杂度太高，需要调动记忆力和理解力才能理解

### 规则 4：不要切碎（防误用）

短句不等于把句子切碎。几个短句可以共同构成一个**意义单元**：

> 病倒的时候，水就在床头，你就是爬不起来。

三句各自独立可懂，但合起来才是一个完整意思。**进阶用法是长短穿插**（短短长 短短长），像打拍子 —— 全短会单调，全长会累。

### 规则 5：结尾不升华

最后一句落在动作或物件上，不落在感悟上。

### 改写后自检

1. 遮住上下文，逐句能读懂吗？
2. 有没有一个只有亲历者才知道的细节？
3. 读者能原样复述这句给别人吗？
4. 有没有禁用词（进行/开展/实现/提升/赋能/某种事物/一件事）？

## 适用边界

| 内容类型 | 是否适用 | 说明 |
|---|---|---|
| 故事 / 案例 / 访谈稿 | 适用 | 天然有动作和场景 |
| 小红书 / 朋友圈 | 部分适用 | 短句与细节有用；但纯客观会削弱共鸣，这两个渠道需要情绪标签 |
| 观点文 / 方法论 / 干货 | 谨慎 | 价值就在概括。只在叙事段落用，观点段落恢复概括 |
| 专业报告 / 课程讲义 | 不适用 | 需要精确术语，简化会损害信息 |
