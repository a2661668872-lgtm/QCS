# 安先生文案与创作系统课学习地图

> 资料性质：新版逐字稿新增的 15 节课程。以下先建立课程链路和学习方法；原始文本未经逐句人工校音，不把 ASR 文本直接当成准确原话。

## 一、课程形成的完整链路

1. **理解平台与受众环境**：先理解内容为什么被看见、被理解和被传播，再谈技巧。
2. **收集选题**：建立持续的选题来源，而不是临时等灵感。
3. **确认选题**：判断选题是否同时具备用户需求、创作者价值和可表达性。
4. **梳理逻辑**：把杂乱思绪整理成观众可以跟随的论证或叙事顺序。
5. **优化内核**：检查价值、情感和节奏，而不只修改措辞。
6. **设计第一句话**：让目标观众迅速知道内容与自己有什么关系。
7. **雕琢细节与文字**：降低理解成本，补足证据、动作、场景和具体信息。
8. **处理商业转化**：广告脚本既要传递内容价值，也要完成可信的行动引导。
9. **预埋验证点**：发布前明确希望验证的停留、完播、互动或转化假设。
10. **补齐旁白、用户思维、创作流程和运营流程**：让方法从单篇写作延伸到稳定生产。
11. **用案例复核**：案例用于理解判断过程，不用于复制表达和结论。

## 二、建议的学习方式

每次只学习一节，并完成一份可检查的产物：

| 课程环节 | 学习产物 |
|---|---|
| 平台机制 | 写出本条内容需要观众完成的连续动作 |
| 选题收集 | 新增 10 条带来源的真实问题或素材 |
| 选题确认 | 写清目标人群、需求、价值、证据与风险 |
| 逻辑框架 | 输出一句主张和 3—5 个必要支撑点 |
| 价值、情感、节奏 | 标注每段在提供什么新信息或情绪变化 |
| 第一句话 | 写 3 个版本，再检查是否准确、自然、不过度承诺 |
| 文字雕琢 | 删除重复和空话，补具体名词、动作、数据来源 |
| 广告脚本 | 写明产品适用对象、证据、限制和行动指令 |
| 数据点预埋 | 发布前登记一个主要假设，发布后只复盘对应指标 |

## 三、应该学习与不能机械学习

应该学习：把写作看成从用户问题到证据、结构、表达、发布和复盘的完整系统；每一步留下可复查的产物；用数据修正具体环节。

不能机械学习：把历史平台经验当成当前官方规则；套用统一“爆款第一句”；为了数据制造争议、虚构经历或夸大效果；将案例表现归因于单一技巧；把“数据点预埋”理解成保证热门。
