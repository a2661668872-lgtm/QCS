# 03 正文写作规范（源自手册第六章，AI 化压缩版）

> 写正文时全程贴身的规范。字数 500-700 字（含标题），信息密度优先——宁可短而精，不要长而水。

## 1. 文案基本要求（六条）

1. 简单易懂：专业词口语化、具象化，降低理解门槛
2. 像朋友聊天：分享好物什么语气就什么语气，不要正式文风
3. 排版舒适：勤分段（每段尽量不超 20-30 字），emoji 分隔点缀
4. 围绕选题：所有内容服务于核心主题，跑题会导致流量分配跑偏（想做美妆却常发其他话题，吸来的就不是看美妆的人）
5. 真实体验：具体细节和真实心得，拒绝空洞赞美
6. 用户视角：用户最关心什么、有什么疑虑？文案有没有回答？

## 2. 四层结构（默认骨架）

1. **开头戳痛点**：第一句话必须让目标用户产生共鸣或好奇。四种开法：设置悬念／直接点名困扰（"你是不是最近…"）／共鸣场景／直接展示结果
2. **衔接造落差**：描述期待，让痛点与美好之间拉开落差
3. **亮解决方案**：足够简单、拿来就能用。每个方法 2-3 行，一篇给 3-5 条，用序号或 emoji 分段
4. **结尾留钩子**：引导互动。留一个疑问句，结尾固定用"评论区有问题随时问。"；正文可留一个信息钩子（"这块细节太多，感兴趣的评论区说"），不强制

## 3. 八大文案结构（按内容类型选用，替代四层结构的备选骨架）

| 结构 | 逻辑链 |
|------|--------|
| 问题解决型 | 遇到问题→渴望改变→试了很多方法不行→（转折）发现新方法→问题解决 |
| 经验分享型 | 展示成果/高光场景→过程心得与技巧→带来的具体改变 |
| 好物推荐型 | 引出产品/契机→多维度介绍（外观/功能/使用感/效果）→客观总结优缺点→适合谁 |
| 对比型 | 抛出对比主题→分别阐述→对比中凸显优势 |
| 信息整理型 | 点明主题（"XX 必备 N 个工具"）→清单式罗列→收藏价值 |
| 攻略教程型 | 明确目标→步骤化拆解→关键节点提示 |
| 避坑型 | 点出常见的坑→分析踩坑原因和影响→给正确方案 |
| 四段式介绍型 | 我是谁+能给你什么→为什么今天分享这个→核心内容要点罗列→引导关注互动 |

**四段式黄金结构**（情绪线版，适合带产品）：遇到问题（皮肤黑被嘲笑）→渴望改变（自卑想变白）→尝试无效（很多方法不满意还长痘）→发现解决（闺蜜推荐 XX 后明显变化）。

## 4. 实用写作技巧

- **代入法**：把读者想象成朋友。你会怎么跟朋友分享/炫耀这件事，就怎么写；写完删掉无关紧要的词句
- **卖点提炼四维**（写产品时）：功能（有什么基础功能）→优势（对比同类好在哪）→利益（这个优势给用户什么具体好处）→感知（五感体验和用户反馈）
- **巧妙植入**：找"选题痛点"和"产品特点"的交集，从场景和痛点切入，产品作为解决方案出现，不突兀推销
- **说人话**：不讲专业概念；用具体场景和真实经历解释，**不用比喻和类比句**（❌"就像 XX 一样"）

## 5. 融入人设（四个方法）

1. 讲"我是怎么做的"，融入个人经验或看法
2. 适当表达情绪：开心就是开心，不开心就是不开心
3. 展示生活性格，让读者隔着屏幕感受到你
4. 少装，真诚

## 6. 排版铁律（违反＝返工）

- 每段不超过 3-4 行（手机屏幕友好）
- **段与段之间不空行**（md 空行复制到小红书会变双倍间距）
- **禁止 markdown 标题语法**（`#`/`##`），用 emoji＋文字做分段标记
- emoji 只用于分段标记（📌 ✅ ❌ 💡），整篇 4-6 个
- 不用加粗斜体等 md 格式符号（小红书不渲染）
- 纯文本输出，可直接复制粘贴

## 7. 真人感四要素（自检第一关）

1. 具体时间场景：用"上个月""周末在咖啡厅"，不用"有一次""之前"
2. 真实情绪变化：从纠结到想通、从焦虑到释然，不全程平铺直叙
3. 细节体验：具体步骤、真实数字、踩坑细节，不用概括性描述
4. 日常口语：用"说白了""但问题是"，不用"综上所述""值得注意的是"

## 8. AI 味排查清单（自检第二关，逐条过）

以下表达必须删除或改写：
- "说个扎心的事实" → 用具体场景切入
- "大多数人低估了…" → 用"我之前也…"
- "事情就完全不一样了" → 用具体变化描述
- "让它被看到" → 用"让需要的人搜到你"

去 AI 化硬清单（写完必查）：
- 没有比喻/类比句（"就像 XX 一样""XX 的发动机"）
- 没有名人引用（"XX 说过一句话"）
- 没有精确夸张对比数字（"快 10 倍""效率差 6 倍"）
- 没有"在这个 XX 的时代"式开头
- 没有三段排比句
- 没有 AI 味开场白（"说个扎心的事实"类）
- 自我解释句不超量（"不是什么高级概念""说白了就是"通篇最多 1 次）

## 9. 互动率优化

- 提升点击：标题有具体数字或明确承诺、戳中情绪或好奇心
- 提升完读：开头直接说"这篇讲什么"；emoji 分段降低阅读压力；每段都有新信息不灌水
- 提升互动：结尾固定"评论区有问题随时问。"

## 10. 话题标签（3-5 个）

第 1 个：内容主题话题 → 第 2 个：场景/人群话题 → 第 3 个：情绪/态度话题 → 第 4-5 个：当前热门相关话题

## 11. 合规红线（贴身检查）

- 没有具体收入数字
- 没有"普通人轻松赚钱"类话术
- 没有导流微信的直接话术（用"评论区扣 1"等软性方式）
- 商单对比测评不拉踩、不攻击竞品
