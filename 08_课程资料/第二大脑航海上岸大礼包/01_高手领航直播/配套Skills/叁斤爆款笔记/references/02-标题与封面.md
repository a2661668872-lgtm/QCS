# 02 标题与封面（源自手册第六章，AI 化压缩版）

> 点击率的胜负手。标题字数 10-20 字（含标点和 emoji），目标是让用户在发现页刷到的一瞬间产生点击欲望。

## 1. 标题三步法（最稳的路径）

1. **收集**：搜同选题的爆款笔记，收集 5-10 个优质标题
2. **拆解**：拆出每个标题里可迁移的关键词和句式（情绪词如"快看！""我简直爱了"、结构词如"XX💰冲下""平替"、场景词如"秋冬的衣柜一定要有"）
3. **模仿重写**：用拆出的关键词句式＋自己的内容，改写出多个备选，择优使用；发出后不火，可以换另一个备选标题改后重发

写作时按此逻辑生成 3 个备选标题，分别走不同技巧路线。

## 2. 六大心理触发技巧

| 技巧 | 用法 |
|------|------|
| 利用人性弱点 | 恐惧（紧迫感/安全感）、懒惰（拿来即用）、从众（跟风效应）、好奇（悬念）、避险（规避风险）、慕强（优秀成果展示） |
| 锁定人群（核心技巧） | 身份标签（年龄/职业/人生阶段："31 岁，已经很棒了…"）＋痛点标签（内耗、拖延、不会写作） |
| 加上数字 | 具体数字替代模糊描述（"5 个方法""3 个雷区""XX 元搞定"） |
| 情绪化前置词 | "突然意识到…""很少有人告诉我们…""真心建议大家…" |
| 极致利他 | 合集型（"读透这 60 本书也能提升写作"）、方法型（"每天 10 分钟，8 个动作"） |
| emoji 点缀 | 适当增加情感表达，纯文字标题同样有效 |

## 3. 九个高效标题句式

蹭热点名人 ／ 指出错误（"你还在 XX？大错特错"）／ 损失厌恶（"不看血亏"）／ 警示（"再不注意 XX，小心 XX"）／ 直击痛点（"30 岁还一事无成？试试…"）／ 展示结果（"30 天做到 XX"）／ 强调简单（"保姆级教程""有手就会"）／ 数字量化 ／ 悬念提问（"XX 的秘密竟然是…"）

## 4. 标题类型配比（批量产出时交替使用）

| 类型 | 占比 | 特征 |
|------|------|------|
| 痛点共鸣型 | 35%（主力） | 戳中目标用户的焦虑 |
| 经验分享型 | 25% | 第一人称建立信任 |
| 数据/清单型 | 20% | 数字增加点击欲望 |
| 反常识/颠覆型 | 10% | 打破常规认知 |
| 对比/测评型 | 10% | 提供对比视角 |

## 5. 标题三原则与禁忌

三原则：
- **吸睛**：瞬间抓住痛点、痒点或好奇心
- **利他**：清晰传达用户能获得什么
- **搜索友好**：包含核心关键词；不用 emoji/谐音字/缩写替代关键词（搜"马尔代夫"搜不到用国旗 emoji 的笔记）；专业词翻译成大白话（"数字游民"→"在家上班"）；模拟用户的搜索习惯选词

禁忌：不用"震惊""绝了""yyds"等纯情绪词堆砌；不做虚假承诺（"日入过千""躺赚""稳赚"）；不用目标用户看不懂的术语。

## 6. 封面建议（输出"封面建议"时按这套）

**核心四要素**：差异性（信息流里能被注意到）、主题明确（一眼知道讲什么）、视觉美感（干净舒适有质感）、吸睛文字（封面字简洁醒目）。

**常见有效类型**：大字报（突出文字）、前后对比图、高颜值真人/产品图、场景氛围图、吸睛拼图、手绘/漫画、聊天记录截图。

**制作关键点**：
- 尺寸 3:4（视觉占比最大）
- 封面风格（色调/字体/版式）保持统一，提升主页专业度
- 文字易读：手机缩小后也看得清；核心信息用大字/亮色突出
- **三色原则**：一个画面主色不超过 3 种，避免花里胡哨分散注意力
- 验证技巧：用小红书"识图"功能搜相似封面，看同款封面的笔记数据如何
