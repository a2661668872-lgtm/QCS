# 岗位AI工作台 · Codex入口规则

> 把本文件放在 Obsidian 库根目录。Codex进入本库后先读本文件。

## 必装 Skill

`skills/job-ai-workbench/SKILL.md`

它负责读取使用者上传的真实岗位资料，根据财务、采购、销售、人事、市场、客服、管理等不同岗位，搭建岗位专属AI工作台，并找出3条值得后续做成Skill的候选工作流。

## 触发规则

用户说出以下任一口令时，完整读取并执行上述 Skill：

- `开始搭岗位工作台`
- `搭我的工作台`
- `岗位资料建库`
- `整理岗位资料`
- `找我的工作流`
- `补充岗位资料`

## 首次使用规则

库内没有 `00_使用说明.md` 和 `01_岗位档案/岗位工作地图.md` 时，视为首次使用。

首次使用必须先：

1. 用大白话说明这个Skill是做什么的、会输出什么、怎么使用。
2. 请用户先上传或放入已有岗位资料。
3. 完整读取已上传资料，先提取已知内容。
4. 资料里已经明确的信息不重复询问。
5. 只追问会影响工作台搭建的关键缺口；没有关键缺口就直接生成。

## 资料保护规则

1. 原始资料不删除、不改写。
2. 已有文件和目录不覆盖；优先沿用原结构。
3. 没有证据的信息标【待补】，不编造。
4. 财务、人事、合同、报价、客户隐私和账号密钥默认按敏感资料处理。
5. AI只做资料整理和工作流识别，不替人审批、付款、签约、录用、解雇或对外发布。

## 安装后的启动词

```text
开始搭岗位工作台
```
