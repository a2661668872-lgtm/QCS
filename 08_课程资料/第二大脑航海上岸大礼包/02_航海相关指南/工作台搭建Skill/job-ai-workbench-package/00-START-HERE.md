# 岗位AI工作台搭建Skill｜先看这里

## 这个包是做什么的

它会根据你所在的岗位和你上传的真实资料，搭建一套属于你的岗位AI工作台。

不同岗位会得到不同内容：

- 财务：财务制度、报销对账资料、审核边界和财务候选工作流。
- 采购：供应商、询价比价、采购规则和采购候选工作流。
- 销售：客户、跟进、方案、成交复盘和销售候选工作流。
- 人事：招聘、面试、入转调离和人事候选工作流。
- 市场/运营：产品、客户、内容、活动和营销候选工作流。
- 客服：知识库、常见问题、异常转人工和客服候选工作流。
- 管理者：会议、目标、项目、决策和管理候选工作流。

它不会直接替你完成全部自动化，也不会在本次搭建完整Skill或Agent。它先把岗位资料和规则整理清楚，再找出最值得后续改造的3条工作流。

## ZIP能不能直接安装

不能在压缩包里直接运行，必须先解压。

最省事的使用方法：

1. 双击 `工作台搭建skill.zip` 解压。
2. 在 Obsidian 新建一个空库。
3. 把解压后 `job-ai-workbench-package` 文件夹里的全部内容复制到空库根目录。
4. 把自己的岗位资料放进库内的 `00_上传资料/`；如果还没有这个目录，可以先新建。
5. 用 Codex 打开这个 Obsidian 库。
6. 对 Codex 说：`开始搭岗位工作台`。

如果你已有自己的 Obsidian 资料库：

1. 先备份原库。
2. 只复制 `skills/job-ai-workbench/` 到原库的 `skills/`。
3. 不要直接覆盖原来的 `AGENTS.md`。
4. 把本包 `AGENTS.md` 交给 Codex，让它合并触发规则，不覆盖旧规则。

## 第一次先上传资料

不要先回答一大堆问题。先把自己已有的岗位资料交给AI。

可以上传：

- 岗位职责、部门目标、周报和工作清单。
- 制度、流程、SOP、表格和模板。
- 历史合格结果、领导修改稿和审核样例。
- 会议纪要、聊天记录、常见问题和异常案例。
- 当前使用的软件、系统截图或导出文件。

敏感资料先脱敏。密码、API Key、身份证、银行卡等不要直接放入资料包。

AI会先完整看一遍：

```text
读取已有资料
→ 提取资料里已经明确的内容
→ 不重复询问
→ 只补问关键缺口
→ 生成岗位工作台
→ 找出3条候选工作流
```

## 搭建后会得到什么

```text
00_使用说明.md
00_上传资料/
01_岗位档案/
02_岗位资料库/
03_对象与协作方/
04_工作流程/
05_规则与审核标准/
06_AI输出区/
AGENTS.md
```

其中的文件名和具体内容会根据岗位动态生成，不会让财务、采购、销售得到同一套空模板。

最终会有：

1. 一份岗位工作地图。
2. 一份已有资料清单和资料源地图。
3. 岗位对象资料：例如客户、供应商、候选人、员工、产品、项目或账务对象。
4. 岗位规则、判断标准、人工审核点和敏感边界。
5. 3条最值得后续AI改造的候选工作流。
6. 最推荐先做的一条及推荐理由。
7. 真正缺失的资料清单。

## 预计时间

- 资料比较齐：20—40分钟。
- 资料较少、需要补问：40—60分钟。

目标是快速搭好岗位底座和找到工作流，不在首次搭建时做完整自动化。

## 本包不包含

- 每周巡检
- 知识库体检
- 定时任务
- 30天计划
- 完整业务Skill
- Agent、飞书、微信或Hermes连接
