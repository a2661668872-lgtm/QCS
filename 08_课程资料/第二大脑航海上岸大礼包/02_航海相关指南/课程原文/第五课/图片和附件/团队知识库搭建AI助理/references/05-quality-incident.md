# 质量问题治理

## 流程

> 接收反馈 → 风险止损 → 证据复现 → 根因定位 → 方案 → 审批 → 修复测试 → 关闭复盘

## 问题类型

- 错误或不完整；
- 已有知识但未命中；
- 真正知识缺失；
- 引用错误或失效；
- 冲突或过期；
- 无依据越界回答；
- 权限异常；
- 下游训练、质检或模板异常。

## 七层根因

1. 原始资料；
2. 知识治理；
3. 知识结构；
4. 检索；
5. 回答规则；
6. 权限；
7. 应用流程。

保留证据链：

> 用户问题 → 用户身份 → 检索内容 → 使用版本 → 回答规则 → 最终输出

不要只修改单个标准答案。修复产生错误的系统原因。

## 回归测试

- 原问题；
- 同义和口语变体；
- 关联问题；
- 无依据、高风险和不同权限边界。

只有关键测试通过并完成留痕后才能关闭。
