# 通用治理规则

## 生命周期

```text
候选资料 → 待处理 → 待审核 → 已发布 → 待更新 → 已失效 → 已归档
```

## 角色

- 业务负责人：决定场景、范围、正式口径和成功标准。
- 内容负责人：维护领域知识并处理更新。
- 审核人：确认准确性、适用范围和生效。
- 运营人：处理资料、反馈、任务和复盘。
- 技术支持：维护平台、集成和权限能力。
- 试点用户：提供真实问题和使用反馈。

小团队可以一人兼任，但每项责任必须有明确承接者。

## 正式知识最低要求

- 唯一标识；
- 标题和类型；
- 业务领域、适用用户和场景；
- 原始来源；
- 当前版本和生效日期；
- 内容负责人和审核人；
- 保密等级；
- 状态；
- 复核日期；
- 被替代或替代关系。

## 更新触发

- 制度、产品、价格、流程或组织变化；
- 新项目、成功案例和失败复盘；
- 用户反馈错误或缺失；
- 资料达到复核日期；
- 内容负责人或权限变化。

## 运行节奏

- 随时：紧急风险；
- 每周：反馈、新资料和未命中；
- 每月：质量和知识缺口；
- 每季度：范围、权限、责任和价值。
