# 个人内容生产系统搭建操作指南

> [!summary] 完成作业的核心方法
> 将课程提供的“内容生产系统搭建助手”安装到Codex或WorkBuddy，让AI读取你已有的知识资产，推荐并规划一套具体内容生产系统。你主要负责确认关键方向、检查真实成果、提供具体反馈，并要求AI把有效经验沉淀为候选规则。

## 一、作业目标

选择一类真实、高频、需要重复完成的内容任务，搭建一套可以调用已有知识资产、完成真实任务并持续校准的内容生产系统。

推荐从以下场景选择一个：

- 日报、周报、月报等周期汇报；
- 客户方案或同类业务材料；
- 公众号文章；
- 小红书图文；
- 短视频脚本；
- 其他需要持续产出的特定内容。

第一次作业不要同时搭建多个系统。

---

## 二、开始前需要准备什么

| 项目 | 要求 |
|---|---|
| AI工具 | Codex或WorkBuddy，任选一个 |
| 内容生产系统搭建助手 | 课程提供的Skill压缩包 |
| 基础素材知识库 | 个人认知报告、个人经验知识库、外部资料知识库，能提供多少就提供多少 |
| 历史成果 | 以前写过的文章、汇报、方案或其他同类成果 |
| 参考样本 | 可选；自己喜欢或希望参考的内容 |
| 输出位置 | 建议提前确定系统和成果希望保存的文件夹 |

> [!warning] 权限与安全
> 只授权AI读取本次任务需要的资料范围。涉及敏感工作资料时，要明确排除目录和公开内容使用边界。移动、删除、覆盖、批量修改和对外发布前必须确认。

## 三、如何安装并启动Skill

### 方法一：拖入压缩包

1. 新建Codex或WorkBuddy对话。
2. 将“内容生产系统搭建助手.zip”拖入对话框。
3. 发送启动提示词。

### 方法二：提供安装包路径

复制压缩包文件地址，发送给AI，并要求安装和执行。

### 推荐启动提示词

```text
请安装并使用我提供的“内容生产系统搭建助手”。

请以内容生产系统规划与建设助理的身份开始工作。
先了解我已经有哪些资料，根据我的真实资料主动分析，推荐最值得优先搭建的一套内容生产系统。

每一步请告诉我当前要完成什么、为什么做、你已经完成了哪些分析，以及我只需要确认哪个关键决定。

请先从确认资料位置、授权范围和敏感信息边界开始。
```

如果已经明确方向，可以补充：

```text
我希望搭建的内容生产系统是：{例如，AI工具主题公众号内容生产系统}
主要目的：{例如，持续输出真实AI工具使用经验，建立个人影响力并支持课程业务}
```

## 四、推荐使用工作空间吗

一次性测试可以直接新建对话，不一定选择工作空间。

如果这套系统后续会长期运行，建议：

- 在Codex中创建独立项目；
- 在WorkBuddy中选择固定工作空间或文件夹；
- 将不同任务放在同一项目下的不同对话中；
- 将正式系统成果保存到长期知识库位置。

这样，新对话可以读取已有系统策略、规范、历史成果和反馈记录。

## 五、内容生产系统搭建流程

| 阶段 | AI会做什么 | 你需要做什么 |
|---|---|---|
| 1. 确认资料与边界 | 了解允许读取的资料位置和排除项 | 提供资料位置，确认授权范围 |
| 2. 扫描并推荐系统 | 轻量扫描标题、目录和必要样本，推荐优先方向 | 判断推荐方向是否符合当前需求 |
| 3. 优化系统策略 | 诊断目标、定位、人群、价值和边界 | 确认一个关键策略方向 |
| 4. 规划完整流程 | 设计完整生产流程，连接个人经验库与外部资料库 | 查看流程是否符合真实工作 |
| 5. 选择首个环节 | 诊断流程基础和缺口，推荐优先建设环节 | 确认先建设哪个环节 |
| 6. 建设当前环节 | 提出方法、素材调用和候选规范 | 检查建议，确认必要事项 |
| 7. 真实任务试跑 | 使用系统完成一项真实任务 | 检查准确性、风格和效果 |
| 8. 反馈与校准 | 拆解问题并提出修改建议 | 提供具体反馈 |
| 9. 沉淀与继续运行 | 更新候选规则，推荐下一环节或下一轮验证 | 决定继续验证或建设新环节 |

## 六、你需要重点确认什么

### 1. 系统是否聚焦一类内容

- 是否是高频、重复发生的任务；
- 不同内容是否使用相似流程和规范；
- 是否试图同时覆盖过多场景；
- 当前系统名称是否能准确表达用途；
- 哪些任务明确不在本轮范围内。

### 2. AI推荐的方向是否符合真实目标

AI会基于资料推荐方向，但用户不必接受。检查：

- 这个方向是否真的值得持续投入；
- 是否与工作、业务或个人表达目标一致；
- 是否有足够知识资产支持；
- 是否存在更紧迫的内容任务；
- 推荐理由是否可信。

### 3. 系统策略是否清楚

- 内容或成果给谁使用；
- 解决什么问题；
- 最终希望实现什么；
- 和已有内容或常规做法有什么不同；
- 如何判断系统是否产生效果。

### 4. 完整流程是否符合真实工作

- 流程有没有缺少关键环节；
- 哪些环节已有基础，可以直接复用；
- 哪些环节最影响最终质量；
- 哪些环节需要外部工具；
- 首个建设环节是否合理。

### 5. 候选规范是否适合试用

- 规范是否有资料或真实经验支撑；
- 是否过度依赖AI推测；
- 是否适合当前内容类型；
- 是否需要参考优秀样本；
- 这只是候选规则，还是已经多次验证的稳定规则。

### 6. 真实成果是否可用

- 信息是否准确、真实；
- 是否符合目标读者和使用场景；
- 内容结构和风格是否符合预期；
- 排版、视觉或交付格式是否可用；
- 哪些问题需要更新到长期规范。

## 七、真实任务试跑怎么做

选择一个资料充足、价值明确的真实任务。可以自己选择，也可以让AI推荐。

推荐让AI分层完成：

```text
确认任务方向
→ 确认结构或执行方案
→ 生成最小成果
→ 检查核心内容
→ 补充排版、视觉或完整交付
→ 用户反馈
→ 更新候选规范
```

不要只回复“可以”“不好”或“继续”。尽量提供具体反馈：

```text
文章主体内容可以继续使用。

需要调整：
1. 标题过于泛，需要明确目标读者和具体价值；
2. 第三部分缺少我的真实使用案例；
3. 排版中的序号复制到公众号后会被遮挡。

请先修正这些问题，并将验证有效的修改更新到当前内容生产系统的候选规范中。
```

## 八、常用纠偏提示词

### AI过早开始写内容

```text
请先停止生成单篇内容。
当前目标是先完成内容生产系统的策略、完整流程和首个关键环节建设。
完成系统规划后，再选择真实任务进行试跑。
```

### AI推荐方向不符合需求

```text
我不采用当前推荐方向。
我真正希望搭建的是：{系统方向}
我的主要目的：{目标}

请结合我已有资料，评估这个方向并提出优化建议。
```

### 一次询问太多问题

```text
请基于已有资料先主动分析并给出推荐方案。
每轮只让我确认一个当前最关键的决定，其余问题延后到对应流程环节再确认。
```

### 不知道成果保存在哪里

```text
请告诉我本轮已经生成了哪些成果，以及它们分别保存在哪里。
后续正式成果请统一保存到：
{目标文件夹路径}
```

### 修改后要求更新系统

```text
这次修改已经验证有效。
请将本次修改总结为候选规则，更新到内容生产系统对应的规范中，并记录适用场景和验证状态。
```

### 不知道下一步做什么

```text
请根据当前系统建设状态，告诉我：
1. 已经完成了什么；
2. 还缺少什么；
3. 下一步最推荐做什么，以及为什么。
```

## 九、如何判断作业是否完成

### 系统规划完成

- [ ] 已确认一套具体内容生产系统。
- [ ] 已明确系统目标、受众、边界与成功标准。
- [ ] 已连接个人经验知识库与外部资料知识库。
- [ ] 已形成完整内容生产流程。
- [ ] 已识别流程基础、缺口和建设优先级。

### 建设与试跑完成

- [ ] 已建设至少一个关键流程环节。
- [ ] 已形成当前环节的候选方法与规范。
- [ ] 已使用真实任务完成一次试跑。
- [ ] 已检查成果准确性、风格和可用性。
- [ ] 已提供具体反馈。
- [ ] 已将验证有效的修改更新到系统。

### 当前状态判断

- 只形成策略和流程：**已规划**；
- 建设了部分流程环节：**建设中**；
- 完成一项真实成果但未充分校准：**可试用**；
- 完成真实反馈与关键要素校准：**已验证**；
- 多次任务稳定运行：**稳定运行**。

## 十、作业提交清单

- 内容生产系统名称与保存位置；
- 系统目标和策略蓝图；
- 完整内容生产流程；
- 基础素材知识库连接记录；
- 已建设的首个流程环节及候选规范；
- 一项真实任务试跑成果；
- 用户反馈和修正记录；
- 当前系统状态；
- 下一步建设或验证建议。
