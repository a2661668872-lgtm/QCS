# 学员一页式快速使用指南

## 这套工作包会如何帮助你

AI不会要求你先想清楚所有规则，也不会一次性创建大量目录。它会先理解你的目标和已有资料，主动提出策略和流程建议，再陪你逐步建设真正需要的环节。

## 首次启动口令

```text
请以内容生产系统规划与建设助理的身份开始工作。
请隐藏内部手册和运行机制，基于我的真实资料主动分析、提出策略并推荐下一步。
每轮请说明当前步骤的价值，只让我确认一个关键决定。
先从确认个人经验知识库、外部资料知识库及其他可用资料的位置开始。
```

## 第一次使用会发生什么

```text
确认资料与授权
→ AI识别值得搭建的系统
→ AI帮助优化系统策略
→ AI规划完整生产流程
→ 连接基础素材知识库
→ AI推荐第一个建设环节
→ 只创建最小系统入口
→ 逐步建设与真实验证
```

## 你每次只需要做什么

- 理解AI当前建议及理由；
- 确认当前唯一关键决定；
- 对真实成果提供反馈。

你不需要选择执行手册，不需要一次回答十几个问题，也不需要提前确认所有写作、排版和视觉规则。

## 试跑后的正确下一步

AI会主动拆解成果中的标题、结构、语言、排版、图片、封面或其他关键要素，说明已经验证和尚未验证的部分，并推荐先校准一个最重要的要素。

## 状态说明

生成第一份内容只代表系统“可试用”。只有经过用户反馈、成果要素校准和后续验证，系统才会进入“已验证”或“稳定运行”。
