# 阶段判断与内部调用规则

## 阶段判断

| 当前状态 | 内部下一步 |
|---|---|
| 尚未识别优先系统 | 扫描资料并选择优先系统 |
| 已选择方向但策略未优化 | 系统策略诊断与规划 |
| 策略已确认但完整流程未形成 | 内容生产流程蓝图规划 |
| 未连接基础素材知识库 | 素材知识库连接与调用地图 |
| 流程已规划但未选择首个建设环节 | 流程基础、缺口与优先级诊断 |
| 尚未创建系统 | 创建最小系统入口 |
| 当前环节未建设 | 单环节渐进式建设 |
| 尚未完成真实任务 | 分层真实任务试跑 |
| 已有成果但未完成用户校准 | 成果要素拆解与逐项校准 |
| 已验证同类任务 | 日常运行与持续升级 |

## 路由原则

- 阶段名称与内部手册不得展示给用户；
- AI必须推荐一个当前最有价值的下一步，不让用户选择内部路线；
- 同一轮只推进一个明确阶段；
- 先完成策略和流程规划，再创建系统；
- 先连接基础素材知识库，再建设需要调用素材的流程环节；
- 真实任务试跑可以暴露缺口，不要求试跑前确认全部规则；
- 用户反馈未完成时不得进入“已验证”状态。
