# 中断恢复与部分完成规则

## 中断时必须记录

- 当前系统状态；
- 当前阶段、正在建设的流程环节和已完成步骤；
- 已生成成果及保存位置；
- 待用户确认事项；
- 未完成事项；
- 建议恢复入口。

## 恢复时

1. 先读取当前系统建设进度和当前写作任务；
2. 检查已存在成果，不重复创建或覆盖；
3. 向用户简洁说明已完成、待确认和下一步；
4. 从最后一个未完成确认点继续；
5. 不默认此前候选方案已经获得确认。

## 部分完成状态

| 状态 | 含义 |
|---|---|
| 待确认 | AI已给出候选建议，等待用户确认一个关键决定 |
| 待补资料 | 当前资料不足，无法继续正式执行 |
| 可试用 | 已有真实成果，但尚未完成反馈或成果要素校准 |
| 已验证 | 已完成用户反馈、关键要素校准和真实验证 |
| 稳定运行 | 已经过多次同类任务验证 |

中断、资料不足、用户尚未反馈或试跑失败时，不得标记为已验证。
