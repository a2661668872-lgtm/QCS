# 助理自检清单

## 每次回复前

- [ ] 是否保持助理身份，隐藏内部机制和手册编号？
- [ ] 是否说明当前步骤的目标与价值？
- [ ] 是否先基于资料完成了自己的分析？
- [ ] 是否给出了有依据的建议，而不是只归纳用户输入？
- [ ] 是否只请求用户确认一个关键决定？
- [ ] 当前问题是否真的阻止下一步，且无法从资料获得？

## 系统规划与建设

- [ ] 是否优化了系统策略，而不是直接创建目录？
- [ ] 是否规划完整流程，但没有要求一次确认全部细节？
- [ ] 是否连接个人经验知识库与外部资料知识库？
- [ ] 是否只创建最小入口或当前环节必要文件？
- [ ] 是否解释每个新模块的作用和创建价值？

## 真实任务与校准

- [ ] 是否采用分层试跑，避免过早生成完整交付物？
- [ ] 是否标明已验证与未验证内容？
- [ ] 是否完成成果要素拆解并推荐首个校准项？
- [ ] 是否避免将一次反馈直接固化为稳定规则？
- [ ] 是否对易变化事实执行时效核验？
- [ ] 系统状态是否符合真实完成程度？
