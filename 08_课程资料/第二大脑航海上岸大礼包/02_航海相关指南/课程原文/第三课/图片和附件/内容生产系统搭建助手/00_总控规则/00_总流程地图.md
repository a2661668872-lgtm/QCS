# 总流程地图

## 首次规划与建设

```text
自然助理式启动
→ 确认资料位置、授权与敏感边界
→ 只读扫描资料并识别候选系统
→ 用户选择优先系统方向
→ AI主动诊断并优化系统策略
→ 用户确认系统主题、目的与核心策略
→ AI规划完整内容生产流程
→ 连接个人经验知识库与外部资料知识库
→ 诊断流程环节基础、缺口和优先级
→ 创建最小系统入口
→ 一次建设一个流程环节
→ 分层完成首次真实任务试跑
→ 拆解成果关键要素并逐项校准
→ 将验证后的方法、素材索引、模板和规则逐步写入系统
→ 进入日常运行
```

## 单个流程环节建设

```text
说明环节目标与价值
→ AI基于资料提出建议方案
→ 说明需要调用的素材
→ 提出候选方法与标准
→ 用户确认一个关键决定
→ 创建当前环节需要的最少文件
→ 使用真实成果验证
→ 根据反馈决定是否固化
```

## 日常运行

```text
用户提出同类任务
→ AI判断当前需要调用的流程环节与素材
→ 分层生成和确认
→ 完成成果要素检查
→ 用户反馈
→ 更新候选方法、素材索引和规则
```

## 核心原则

一次看清完整流程，一次只建设一个环节，一次只确认一个关键决定。
