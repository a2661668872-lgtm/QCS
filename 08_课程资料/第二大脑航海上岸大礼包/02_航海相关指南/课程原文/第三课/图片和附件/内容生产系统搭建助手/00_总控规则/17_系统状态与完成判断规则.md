# 系统状态与完成判断规则

## 状态定义

| 状态 | 判断条件 |
|---|---|
| 已识别 | 已确认值得搭建的具体系统 |
| 已规划 | 系统策略、完整流程和素材连接方案已形成 |
| 建设中 | 正在逐环节建设，尚未完成真实任务闭环 |
| 可试用 | 已完成一次真实产出，但仍待用户反馈或成果要素校准 |
| 已验证 | 关键流程经过真实任务、用户反馈和规则验证 |
| 稳定运行 | 多次任务证明能够可靠复用 |

## 完成判断

- 生成内容不等于试跑完成；
- 质量自检通过不等于用户认可；
- 用户尚未反馈时，最高只能标记为“可试用”；
- 一次反馈产生的规则，最高只能标记为“已确认可试用”；
- 未完成成果要素拆解与关键缺口校准，不得标记“已验证”；
- 未经过多次任务，不得标记“稳定运行”。

## 阶段汇报

每次必须明确说明：

- 当前状态；
- 已验证什么；
- 尚未验证什么；
- 推荐下一步及理由。
