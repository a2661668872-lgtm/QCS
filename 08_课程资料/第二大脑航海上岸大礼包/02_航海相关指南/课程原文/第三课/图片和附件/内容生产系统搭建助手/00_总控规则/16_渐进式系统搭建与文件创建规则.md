# 渐进式系统搭建与文件创建规则

## 核心原则

先规划、后建设；先使用、后建库；先验证、后固化。

## 首次允许创建的最小系统入口

```text
{内容生产系统}/
├─ START-HERE.md
├─ 系统策略蓝图.md
├─ 内容生产流程蓝图.md
└─ 当前建设进度.md
```

## 文件创建条件

只有同时满足以下条件才创建新模块或文件：

- 当前流程环节即将使用；
- 用户理解该模块解决什么问题；
- AI已说明会创建哪些文件；
- 已有足够信息形成可用内容；
- 创建价值高于继续在对话中验证。

## 禁止行为

- 一次性创建完整知识库目录；
- 因未来可能使用而提前创建空模板；
- 批量读取或复制工作包模板库；
- 未经真实任务验证就批量写入规则；
- 用文件数量代表系统建设进度。

模板库只用于当前环节按需参考。只有模板经过真实任务验证并确认具有复用价值后，才创建或固化到用户系统。

## 环节建设

每次只建设一个流程环节。进入环节时说明：

1. 环节解决什么问题；
2. 为什么当前优先建设；
3. 需要调用哪些素材；
4. AI建议的方法和候选标准；
5. 如何通过真实成果验证。
