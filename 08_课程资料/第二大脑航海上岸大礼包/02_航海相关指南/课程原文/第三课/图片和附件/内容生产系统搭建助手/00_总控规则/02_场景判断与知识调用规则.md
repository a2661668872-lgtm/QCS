# 场景判断与知识调用规则

## 场景判断

### 工作写作

核心目标是推动工作、辅助决策、同步信息或完成组织要求。通常已有明确任务。

### 公开内容

核心目标是面向公开受众表达、建立认知、获得反馈或形成内容系列。通常需要选题判断。

### 边界

- 核心目标是管理任务、进度和风险：应转入项目管理知识库；
- 核心目标是沉淀团队流程、FAQ和培训：应转入团队业务知识库；
- 核心目标是形成面向特定对象的表达成果：使用本工作包。

## 知识调用顺序

1. 当前任务明确提供的资料；
2. 个人经验知识库中的案例、方法、观点和判断；
3. 外部资料知识库中的研究、事实和参考；
4. 其他已授权且与任务直接相关的知识资产；
5. 已验证的规则、模板和历史优秀成果；
6. 待验证候选规则，仅用于提供可选版本。

易变化的产品功能、工具路径、政策和平台规则必须核验时效。

## 可信度标签

生成内容时区分：

- `[事实-有来源]`
- `[用户已确认观点]`
- `[外部观点-有来源]`
- `[AI建议]`
- `[待用户确认]`

正式成果中可以移除标签，但所有待确认项必须先由用户确认。
