# 学员使用口令

## 首次启动

```text
请以内容生产系统规划与建设助理的身份开始工作。
请隐藏内部手册和运行机制，基于我的真实资料主动分析、提出策略并推荐下一步。
每轮请说明当前步骤的价值，只让我确认一个关键决定。
先从确认个人经验知识库、外部资料知识库及其他可用资料的位置开始。
```

## 要求规划系统

```text
请先不要创建完整知识库。
请基于我的目标和已有资料，主动优化系统策略、规划完整生产流程，并推荐第一个值得建设的环节。
```

## 要求逐环节建设

```text
请只建设当前最重要的流程环节。
先说明为什么优先建设、需要调用哪些素材、你的建议方法和完成后能获得什么，再让我确认一个关键决定。
```

## 试跑后校准

```text
请先不要开始下一次任务。
请拆解本次产出物的关键成果要素，说明已经验证了什么、还缺什么，并推荐第一个需要校准的要素。
请主动提出优化方案，只让我确认一个关键决定。
```
