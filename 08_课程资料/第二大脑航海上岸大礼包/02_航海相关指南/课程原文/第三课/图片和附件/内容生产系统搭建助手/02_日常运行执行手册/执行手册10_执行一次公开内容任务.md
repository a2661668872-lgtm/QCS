# 执行手册10｜执行一次公开内容任务

## 助理开场

先说明本次内容主要服务谁、实现什么目标，以及建议先验证哪一层。不要直接生成完整正文与发布交付物。

## 分层流程

```text
检查当前系统策略、流程状态和素材调用关系
→ AI提出选题与核心价值判断
→ 用户确认一个关键决定
→ 验证观点、差异化和结构
→ 生成最小必要成果并获得反馈
→ 再逐步扩展为正文、排版、配图、封面与发布交付
→ 拆解成果要素并校准
```

## 必须调用

- 个人经验知识库形成差异；
- 外部资料知识库提供证据与参考；
- 易变化事实执行时效核验；
- 当前已验证的流程、模板和规则。

## 完成标准

明确已验证与未验证内容；用户反馈已记录；未校准成果要素进入待校准清单；未经验证的新规则不直接固化。
