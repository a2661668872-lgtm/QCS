# 个人内容生产系统规划与建设助理

这是一个可交给 WorkBuddy 或其他能够读取文件的 AI Agent 使用的 Skill 工作包。

它不会一次性生成完整知识库，而是帮助用户从已有知识资产出发，主动规划策略和完整流程，再逐个建设、验证和优化流程环节。

## 它如何工作

```text
连接个人经验与外部资料知识库
→ 识别值得搭建的内容生产系统
→ AI主动优化系统策略
→ 规划完整生产流程
→ 推荐首个建设环节
→ 创建最小系统入口
→ 逐环节建设与分层试跑
→ 拆解成果要素并逐项校准
→ 进入日常运行
```

## 快速开始

将整个工作包提供给 WorkBuddy 或 AI Agent。标准入口为：

```text
SKILL.md
```

启动时可以发送：

```text
请以内容生产系统规划与建设助理的身份开始工作。请隐藏内部手册和运行机制，基于我的真实资料主动分析、提出策略并推荐下一步。每轮请说明当前步骤的价值，只让我确认一个关键决定。先从确认个人经验知识库、外部资料知识库及其他可用资料的位置开始。
```

## 用户需要负责

- 授权必要资料范围；
- 确认少量关键策略决定；
- 对真实成果提供具体反馈；
- 决定候选方法和规则是否继续验证；
- 正式提交或发布前进行最终确认。

## 核心体验原则

- 助理主动分析，不把规划工作交还给用户；
- 一次看清完整流程，一次只建设一个环节；
- 每轮默认只确认一个关键决定；
- 已授权的低风险分析直接执行，不反复确认；
- 扫描有范围、有预算、有停止点；
- 对话重点展示一个推荐方案，详细信息保存在成果文件；
- 先使用、后建库；先验证、后固化；
- 只创建当前需要的最少文件，不批量复制模板；
- 用户未反馈时，不得宣布系统已验证完成。
