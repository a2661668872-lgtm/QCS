# 执行手册8｜拆解成果要素并逐项校准

## 目标

真实试跑后，根据实际产出物主动识别关键成果要素、诊断系统缺口，并一次只校准一个最重要的要素。

## 动态成果要素

不同产出物应动态拆解。例如：

- 公众号文章：内容策略、标题、核心观点、结构、语言、篇幅节奏、排版、配图、封面、摘要和发布格式；
- 客户方案：目标、需求理解、方案逻辑、证据、商务表达、版式和行动建议；
- 视频脚本：开场、信息节奏、口播语言、镜头提示和行动引导。

## 校准流程

```text
识别产出物关键要素
→ 判断哪些已有标准
→ 判断哪些仍未确认或验证
→ 诊断最影响效果的缺口
→ 推荐第一个需要校准的要素
→ AI提出判断、优化建议和候选方案
→ 用户确认一个关键决定
→ 更新候选方法、模板或规则
→ 下一次任务继续验证
```

## 规则沉淀

反馈必须区分：

- 通用质量底线；
- 系统策略标准；
- 用户风格偏好；
- 本次任务要求；
- 需要后续验证的候选规则。

一次反馈不得直接成为稳定规则。

## 完成标准

已明确本次试跑验证了什么、还缺什么；至少完成一个关键成果要素的首次校准；系统状态按真实验证程度更新。
