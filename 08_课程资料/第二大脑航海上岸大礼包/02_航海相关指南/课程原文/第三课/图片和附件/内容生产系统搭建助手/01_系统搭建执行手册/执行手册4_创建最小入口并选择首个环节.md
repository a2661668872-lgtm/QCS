# 执行手册4｜创建最小系统入口并选择首个建设环节

## 目标

在策略与完整流程明确后，只创建能够支持继续工作的最小系统入口，并选择第一个需要建设和验证的流程环节。

## 首次只创建

```text
{内容生产系统}/
├─ START-HERE.md
├─ 系统策略蓝图.md
├─ 内容生产流程蓝图.md
└─ 当前建设进度.md
```

## 首个环节选择标准

- 是否是当前最大瓶颈；
- 是否影响后续多个环节；
- 是否已有资料能够支持；
- 是否能快速形成用户可感知成果；
- 是否适合用真实任务验证。

## 用户引导

AI必须说明：

- 为什么推荐先建设这个环节；
- 完成后用户将获得什么；
- 这次会创建哪些必要文件；
- 哪些模块暂时不会创建。

用户只确认是否按照推荐从该环节开始。

## 完成标准

已创建最小入口；已确定首个建设环节；未批量创建其他目录、模板或规则文件。
