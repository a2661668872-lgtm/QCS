四、什么是Skill
4.1 Skill的定义
Skill = 基于某套知识经验流程模板、检查清单和风险规则封装出来的AI执行能力。
说白了，Skill就是给AI用的标准化工作执行手册（SOP）。
维度
说明
本质
一个文档（不是程序）
需要编程吗
不需要，每个人都可以做
谁来做
可以让AI来帮你做
怎么用
把压缩包发给AI，它读README后按总控规则调用所有文件

4.2 Skill工具包的内部结构
Skill压缩包/
├── README（AI首先读取的说明书）
├── 执行手册
├── 执行流程
├── 各种规则文件
└── ...

AI的读取逻辑：先读README→根据总控规则→调用所有相关文件→按标准化流程执行。
4.3 Skill的迭代
Skill不是一次成型的，需要经过验证和反馈修改
从规划到可用版本大约需要20次对话迭代
初始版本未必能直接执行，把它看成"养孩子"的过程
持续补充资料、持续整理，最终变成有独特经验的执行Skill

七、职场三大核心燃料
7.1 来源
来自《远见》一书的核心知识点：在职场前10年需要积累的三大燃料。
7.2 三大燃料详解
燃料
定义
关键区分
技能
你能教会别人干什么
不是"你会什么"，而是"你能教什么"
作品
体现专业性的案例
如"运营过3个用户过亿的产品" vs "干了15年运营"
人脉
三种人：贵人、支持者、关键同志
不是巴结，而是做对他有用的事

7.3 三者的循环增强关系
技能 → 做出作品 → 表达出来被人看见 → 结识三类人脉
&#x20; ↑                                          ↓
&#x20; ← ← ← ← ← 反馈与机会 ← ← ← ← ← ← ← ←

7.4 维护人脉的核心逻辑
不是巴结贵人，而是做对他有用的事，成为他需要的"关键同志"。
低姿态、一味逢迎→贵人越不搭理你
主动表示"我可以帮你做什么，看你需不需要"→成为他的关键同志
