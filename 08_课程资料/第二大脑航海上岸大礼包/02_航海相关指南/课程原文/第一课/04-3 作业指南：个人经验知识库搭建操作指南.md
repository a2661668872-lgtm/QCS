# 个人经验知识库搭建操作指南
> [!summary]
> 完成作业的核心方法 用课程提供的Skill压缩包 + 启动提示词，让WorkBuddy或Codex自动执行个人经验知识库的搭建。你的职责是：确认选项、选择方向、在Obsidian中查看成果并反馈。
一、先理解Skill工具包
Skill工具包是一个压缩包文件，里面包含：
README（AI首先读取的说明书）
执行手册
执行流程
各种规则文件
你不需要去读压缩包里的文件。 AI会先读README，然后根据总控规则自动调用所有相关文件，带着你逐步完成知识库搭建。

三、通用操作方法
3.1 如何提交压缩包给AI
方法一：拖拽（推荐）
直接将压缩包拖入WorkBuddy/Codex的对话框
方法二：粘贴路径（拖拽失败时）
将压缩包保存到电脑（桌面或任意位置）
右键压缩包→"复制文件地址"
在对话框中粘贴路径
> [!info]
> 小技巧 告诉AI文件路径让它直接读取，比让它扫描全盘更省积分。3.2 如何选择项目保存位置
在AI对话框下方，点击"打开本地工作空间"
找到你的Obsidian知识库文件夹
新建"个人经验知识库"文件夹（或选择已有的）
选择该文件夹
这样AI执行过程中沉淀的所有文件都会保存在该文件夹中。
3.3 建议的协作模式
左边：WorkBuddy或Codex的对话框
右边：Obsidian知识库（打开AI产出的文件夹）
AI告诉你"执行完了"，你就到知识库里查看成果，然后给它反馈。
如果AI不给你文件预览链接，可以告诉它："把预览链接给我"，说一次后它后续会自动提供。

四、作业：搭建个人经验知识库
作业目标
使用Skill工具包，让AI自动完成个人经验知识库的搭建，包括：主题定义→资料导入→路线图→经验卡→方法卡→知识树→Skill执行包→更新机制。
使用的Skill工具包
课程群中提供的"个人经验知识库搭建Skill压缩包"。
启动方式
在WorkBuddy或Codex中新建对话
拖入Skill压缩包（或粘贴压缩包路径）
复制课程群中的启动提示词，粘贴到对话框
选择Obsidian知识库中的保存位置
发送
启动提示词格式参考：
{从课程群中复制的完整提示词}

AI会怎样引导你
AI会按以下10个阶段引导你完成搭建：

你需要重点确认
- [ ] 主题选择：AI建议的主题是否是你真正想整理的经验方向
- [ ] 资料范围：AI扫描到的资料是否完整，有没有遗漏的重要文件
- [ ] 经验路线图：主干流程是否覆盖了你的核心工作环节
- [ ] 经验卡内容：提炼的经验是否准确反映了你的实际做法
- [ ] 方法卡组合：经验卡的组合方式是否符合你的工作逻辑
- [ ] 知识树结构：7大要素（主题总览/方法论/场景/问题分支/案例/工具/风险）是否完整
- [ ] Skill可执行性：初始Skill未必能直接执行，了解它的当前能力和升级方向
- [ ] AI引导的问题：AI让你确认的事情直接确认就好，不需要想太多
> [!important]
> 如果拿不准怎么选 跟AI说"按你的建议来"，它就会继续往下执行。先把整个过程走完比每一步纠结更重要。Skill工具包预设的最终成果

五、后续维护与使用指南
5.1 日常维护
将新增的工作资料文件放入"待AI整理"文件夹
在AI对话中说："按照Skill工作包的整理流程，去整理"
AI会自动归类资料→提炼经验卡/方法卡→更新知识库
收集到一定程度可以让AI检查Skill是否可以更新
5.2 设置自动化
在WorkBuddy/Codex中设置定时任务：
让AI定时检查"待AI整理"文件夹是否有新增资料
有新增资料则自动执行整理
5.3 调用知识库产出成果
完成搭建后，你可以让AI：
生成个人介绍（告诉AI合作对象和需求）
生成业务方案
撰写工作总结/计划
产出文章和短视频文案
设计简历/海报/官网
使用方式：直接告诉AI你的具体需求，它会从知识库中调取相关资料来生成。
