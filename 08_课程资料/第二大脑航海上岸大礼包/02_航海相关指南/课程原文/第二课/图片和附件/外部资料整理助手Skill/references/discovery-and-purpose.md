# 资料发现与目的引导

## 一、先找到资料

### 用户指定位置

确认位置存在并轻量盘点：

- 文件与子目录数量；
- 文件类型分布；
- 大文件和长资料候选；
- 最近更新时间；
- 明显重复与异常文件；
- 在线链接或知识库入口。

### 用户不知道位置

优先推荐扫描顺序：

1. 用户指定的常用资料目录；
2. 文档、下载、桌面或工作项目目录；
3. 用户明确授权的磁盘。

不要默认扫描系统目录、应用缓存、代码依赖、回收站和隐私敏感目录。

先只读取元信息，输出候选位置清单，再推荐缩小后的深读范围。

## 二、目的定义

足以指导定向整理的目的包括：

```text
目标任务 + 使用对象或场景 + 期望帮助
```

用户只提供一部分时，先根据资料和上下文补成目的草案，不连续追问。

## 三、用户没有明确目的

先抽样分析资料：

- 高频主题与工具；
- 资料角色：教程、案例、方法、报告、观点、数据等；
- 内容完整性与时效；
- 现有资料能够共同支持的任务；
- 明显资料缺口。

然后推荐 2 至 4 个差异明确的知识库方向。每个方向说明：

- 知识库主题；
- 未来能够帮助用户完成什么；
- 适合谁使用；
- 预计优先整理哪些资料；
- 可能形成哪些类型的素材；
- 局限与风险。

给出一个推荐默认方向，让用户只需确认或选择编号。

## 四、方向推荐标准

优先推荐：

- 现有资料覆盖充分；
- 能解决明确问题；
- 用户未来可能反复使用；
- 整理成本与价值匹配；
- 能形成独立可复用素材；
- 不依赖大量缺失资料才能成立。

避免推荐：

- 只根据一份资料就过度扩大主题；
- 主题过宽且无法定义停止条件；
- 主要依赖过时、残缺或低可信资料；
- 直接跳到选题、写作或发布，而非资料整理。

## 五、目的成熟度

| 状态 | 助理动作 |
|---|---|
| 未明确 | 分析资料并推荐方向 |
| 可启动 | 建立资料认知，不做强目的排序 |
| 可定向整理 | 动态评估并制定整理方案 |
| 可直接交付 | 按明确成果与验收标准执行 |
