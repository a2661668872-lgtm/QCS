# 在线大型知识库探索

## 核心判断

大型在线知识库需要先发现链接，再筛选和整理内容。边发现边深读容易过早聚焦并遗漏相关分支。

## 链接类型

- 目录节点；
- 内部页面；
- 当前页面锚点；
- 外部页面；
- 附件和媒体；
- 重复、失效或无权限链接。

## 链接队列字段

- 标题和标准化链接；
- 链接类型；
- 所在层级与父页面；
- 从哪些页面被发现；
- 当前访问状态；
- 与用户目的的潜在关系；
- 下一步处理决定；
- 未继续处理原因。

## 探索流程

```text
建立种子入口
→ 扫描目录节点和当前页面链接
→ 标准化与去重
→ 轻量识别页面角色
→ 按目的选择高价值分支
→ 深读代表页面
→ 将新发现链接返回队列
→ 达到停止条件
→ 输出覆盖报告
```

## 去重

- 移除不影响内容的查询参数；
- 将同页不同锚点合并，并保留章节列表；
- 同一页面从不同路径发现时保留所有来源路径；
- 不只按标题判断重复；
- 必要时使用内容指纹识别转载与镜像。

## 停止条件

- 已覆盖用户指定主题；
- 连续若干页面没有新增高价值信息；
- 达到用户确认的页面、时间或深度预算；
- 新链接主要为重复、低相关或无限外部延伸；
- 继续探索成本高于潜在价值。

## 完整性表达

不要声称“已经抓取所有有用页面”。应说明：

- 种子入口；
- 已扫描分支；
- 已发现、访问、深读数量；
- 未访问链接与原因；
- 停止条件；
- 建议未来继续探索的分支。

## 增量更新

保存页面标识、标准化 URL、更新时间或内容指纹。下一轮优先处理新增、变化、失效和权限变化页面。
