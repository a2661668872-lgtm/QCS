# 宿主适配

## 通用原则

- 先探测当前宿主实际可用能力，不按文档猜测。
- 缺少某项能力时使用低风险降级路径。
- 用户只处理登录、授权、管理员审批和其他不可替代动作。
- 不修改宿主内部状态来伪装安装或授权。

## Codex

- 使用本地文件和命令能力进行盘点、指纹、台账和验证。
- 需要在线登录态时，在用户确认后使用可用浏览器能力。
- 查找插件、连接器和专用文件处理能力时先进行工具发现。
- 批量写入前展示计划并确认。
- `agents/openai.yaml` 仅用于 Codex 界面增强，不是核心流程依赖。

## WorkBuddy

- 优先使用当前已安装的连接器与文件能力。
- 连接器缺少时先说明收益与无安装替代路径，再请求确认。
- 连接器权限不足时区分枚举、搜索、正文、附件等能力，继续当前可读范围。
- Skill 核心只依赖标准 `SKILL.md`、references、scripts 和 assets。

## 其他智能体

- 映射同等文件、网页、文档和脚本能力；
- 无法自动扫描时生成用户可执行的最小操作；
- 无法运行脚本时，仍可按参考规则人工完成小批次整理；
- 明确说明实际能力和覆盖范围。
