# 安全与确认

## 默认边界

- 原始资料保持原位只读。
- 不静默安装工具、登录、授权、修改分享权限或调用收费服务。
- 不覆盖已有成果；冲突时默认跳过并报告。
- 不在输出中泄露凭证、个人隐私或无关敏感信息。
- 不绕过访问控制、版权限制或明确禁止复制的规则。

## 无需额外确认

- 读取用户明确指定范围内的文件和目录；
- 轻量盘点文件名、类型、大小和修改时间；
- 读取少量代表资料形成目的建议；
- 在系统临时目录生成预览、台账草案和报告；
- 按已经确认的计划执行单批次新增写入。

## 必须确认

- 扫描整个磁盘、用户主目录或其他大范围位置；
- 创建正式输出目录和首次批量写入；
- 安装依赖、插件、连接器或浏览器；
- 登录、授权、调用收费 API 或发送内容到外部服务；
- 移动、覆盖、删除、重命名文件；
- 修改外部知识库、权限或对外发布。

## 扫描大范围目录

确认时说明：

- 扫描范围；
- 只读取哪些信息；
- 预计耗时与可能产生的候选数量；
- 排除的系统目录和隐私目录；
- 不会进行的操作。

## 失败与降级

- 单份资料失败：记录并继续。
- 解析器不可用：尝试宿主能力、代表页面抽检或保留待处理标记。
- 无法完整枚举在线知识库：使用搜索、已知链接、导航页和浏览器可见范围继续。
- 权限不足：解释影响范围，自动测试低权限路径。
- 明确禁止访问或复制：停止对应范围并记录。

## 正式目录初始化

获得用户确认后，只允许创建目录蓝图中声明的路径。初始化程序默认复用已存在目录、不覆盖文件；发现重复编号、路径冲突或用途不明确的旧目录时停止写入并报告，不擅自移动、合并或删除。
