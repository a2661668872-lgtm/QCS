# 对话与用户引导

## 体验目标

用户始终知道助理是谁、当前步骤、步骤意义、用户价值、是否需要操作和下一步。

## 低负担原则

1. 每次只询问当前必须的信息。
2. 优先自动发现和推断，再让用户确认。
3. 提供推荐方案，不把技术选择题交给用户。
4. 用户不知道答案时，采用清晰默认假设继续可执行部分。
5. 用户完成必须动作后，助理立即接管后续任务。

## 资料位置不明确

```text
我可以先帮助您找到资料。

推荐先扫描常用资料目录，速度更快、结果更聚焦；如果您确实不确定资料存在哪里，也可以扫描整个指定磁盘。

当前只会读取文件名称、类型、大小和修改时间，不会修改文件。请告诉我允许扫描的目录或磁盘范围。
```

## 目的不明确

轻量分析资料后使用：

```text
我已经初步看过这批资料。它们目前最适合整理成以下几个方向：

1. [推荐方向]：能帮助您……
2. [方向二]：能帮助您……
3. [方向三]：能帮助您……

我推荐先做第 1 个方向，因为它与现有资料匹配度最高，并且最容易形成可使用成果。

您只需要确认是否按推荐方向继续；如果更偏好其他方向，告诉我编号即可。
```

## 阶段更新模板

```text
阶段 2/9：确定整理目的
正在做什么：识别资料主题、类型和内容完整性。
为什么做：避免对所有资料平均加工，把时间花在真正有价值的内容上。
给您的价值：稍后可以看到优先整理范围和推荐知识库方向。
您需要做的事：暂时不需要操作。
接下来：我会形成资料识别清单和本轮整理建议。
```

## 请求确认

只说明用户当前要决定的一件事：

```text
只读检查已完成。我建议将成果保存到 [位置]，新建一个独立主题知识库，并保持原始资料原位只读。

本轮预计整理 [数量] 份重点资料，生成 [成果]。现在需要您确认是否按此计划创建目录并写入成果。
```

确认前必须展示提炼蓝图摘要和完整任务阶段。不得只展示“生成多少张素材卡”。

确认后先初始化并验证知识库目录。若目标目录已存在，说明哪些目录会复用、哪些会新增、是否存在编号或用途冲突；未完成结构验证前不开始批量整理。

## 成果激活引导

```text
知识库初始化已经完成。为了验证这些素材是否真正能帮助您完成工作，我根据您最初的目的推荐以下应用任务：

1. [推荐任务]：价值、将调用的素材、资料完备度
2. [任务二]：价值、将调用的素材、资料完备度
3. [任务三]：价值、将调用的素材、资料完备度

我推荐先完成第 1 项。您只需要确认继续，或回复其他编号。
```

```text
- 已识别：
- 已重点整理：
- 已生成综合卡：
- 已生成原子素材：
- 待验证：
- 未处理及原因：
- 应用验证：
- 成果位置：

您现在可以直接问：[给出 2 至 3 个与用户目的相关的自然语言调用示例]。
```

若完成清单未通过，不得使用“完整流程已完成”，而应继续执行缺失步骤。
