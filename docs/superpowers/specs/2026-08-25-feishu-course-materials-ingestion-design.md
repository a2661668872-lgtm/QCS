# 飞书航海资料收录设计

## 目标

把飞书页面“第二大脑航海上岸大礼包”中的资料按原页面分类收录到当前 Obsidian 主库，形成可离线保存、可搜索、可追溯的课程资料区，同时不污染现有的对标素材、内容规律、内容草稿和正式 Skill。

## 来源与范围

- 主来源：`https://e026fgkhro9.feishu.cn/wiki/MpJpwHnOciuDDskH7Bocnt37nUg`
- 页面分类：高手领航直播、航海相关指南、常用工具。
- 收录安全的 PPT、PDF、Markdown、课程文档和 Skill ZIP。
- 飞书文章在权限允许时转成 Markdown，并保留原始链接、页面标题、作者和收录日期。
- 工具类资料只建立用途与链接索引，不安装、不运行、不验证登录或授权。

## 目标结构

```text
08_课程资料/
└── 第二大脑航海上岸大礼包/
    ├── 资料总览.md
    ├── 01_高手领航直播/
    ├── 02_航海相关指南/
    ├── 03_常用工具/
    │   └── 工具索引.md
    └── _原始附件/
```

- `资料总览.md` 是这批资料的局部导航，记录分类、来源、保存状态和对应本地路径。
- `01_高手领航直播/` 保存五场直播的课件、提示词和配套 Skill。
- `02_航海相关指南/` 保存九类指南，其中 Codex 与 Obsidian 课程按先导课至第五课继续分组。
- `03_常用工具/工具索引.md` 记录工具用途、公开地址、来源和安全说明，不存放工具安装包。
- `_原始附件/` 保留下载到本地的原始文件；可读内容按分类建立 Markdown 导航或安全解压副本。

## 收录规则

1. 不覆盖同名文件；遇到重名时保留原文件名并增加来源或版本后缀。
2. 原始附件与整理后的 Markdown 分开保存，整理稿始终指回原始附件或原始链接。
3. ZIP 只解压文档、文本和 Skill 源文件；先检查条目路径与文件类型，拒绝路径越界，不运行任何内容。
4. PPT、PDF 和 Markdown 原件直接保存；需要摘要时另建 Markdown，不改写原文件。
5. 页面或附件无权限、链接失效或下载失败时不猜测内容，在总览中标记“无权限”或“下载失败”。
6. 资料状态统一使用“已本地保存”“仅保留链接”“无权限”“下载失败”四类。
7. 不修改 `00_个人背景` 至 `07_AI编导系统`、现有 `skills`、Obsidian 配置或 Agent 规则。

## 安全边界

- 不下载或收录“剪映破解版”。
- 不下载可执行程序、浏览器扩展和用途不明的二进制工具。
- 不收录或传播临时授权码、会员激活信息、提取码等凭证性内容。
- GitHub 工具、在线工具和 Obsidian 第三方插件只记录公开项目地址或名称，并标注“使用前自行审查”。
- 不安装软件、不启用插件、不提交表单、不修改云端权限。

## 执行顺序

1. 盘点主页面三类资料及全部子链接，建立预期清单。
2. 创建独立课程资料目录和局部导航。
3. 下载安全附件，读取或转换可访问的飞书文档。
4. 对安全 ZIP 做受控解压，把可读内容放入对应分类。
5. 生成工具索引，只保留安全的公开地址和用途说明。
6. 核对预期清单与本地文件，补全每项状态、来源和本地路径。

## 异常处理

- 跨租户飞书页面要求额外登录时，停止该项并标记“无权限”，不尝试绕过。
- 下载按钮未暴露稳定链接时，使用页面允许的正常下载操作；失败后记录状态，不反复猜测接口地址。
- 文档转换无法保留复杂版式时，优先保存原件，Markdown 只承载正文和来源信息。
- 安全检查发现可执行文件、脚本安装器或越界路径时，不解压该项，并在总览中说明原因。

## 验收标准

- 已建立一个独立的 `08_课程资料/第二大脑航海上岸大礼包/` 资料区。
- 主页面的 5 类直播、9 类指南和 11 类工具均在总览中有对应记录。
- 所有可安全下载且有权限访问的课件、文档和 Skill 包均有本地文件或明确失败状态。
- 每项都能追溯到原始飞书页面或公开项目地址。
- 工具索引不包含破解版下载地址、临时授权码或可执行工具附件。
- 没有安装、运行或启用任何下载内容。
- 未修改当前任务范围外的业务文件和 Obsidian 配置。
